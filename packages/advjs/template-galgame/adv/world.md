# {{projectName}} · 世界观

## 基本设定

- **类型**：校园恋爱 galgame（多女主路线 + 好感度系统）
- **时代**：现代日本，202X 年
- **主要地点**：临海县立樱丘高中
- **基调**：青春、暧昧、轻喜剧

## 核心玩法

这是一个 galgame（美少女恋爱游戏），核心循环是：

1. **日常相处** —— 主人公在不同场景与各女主互动
2. **选择** —— 玩家的选择影响对应女主的「**好感度**」
3. **路线分歧** —— 好感度累积到阈值后进入该女主的「**个人线**」
4. **结局** —— 每条个人线有自己的 TRUE / GOOD / BAD END

## 好感度系统

- 每个女主有独立的好感度数值（`attributes.galgame.affinityInitial` 为初始值）
- 选项、送礼、关键事件都会增减好感度
- 章节末根据当前最高好感度决定路线走向
- 好感度不应外显为冰冷数字，应通过女主的态度变化体现

## 美术风格

- **整体风格**：明亮的日系赛璐珞，柔和高光
- **色彩基调**：以粉、米白、天蓝为主，强调季节与时间光线
- **角色设计**：立绘需多表情差分（笑、害羞、生气、困扰）

## 叙事原则

- 每条女主线都要有独立的核心冲突，而非只是「攻略对象」
- 暧昧靠潜台词和留白，不要直白说「我喜欢你」
- 选项之间不应有明显「正确答案」，但应有性格倾向
