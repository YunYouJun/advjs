# 术语表

> 保持术语一致，避免同一概念出现多种叫法。

| 术语     | 英文 / 别称     | 含义                                   |
| -------- | --------------- | -------------------------------------- |
| 好感度   | affinity        | 女主对主人公的好感数值，影响路线与结局 |
| 共通线   | common route    | 所有女主共享的前期剧情，路线分歧前     |
| 个人线   | character route | 某位女主的专属剧情，好感度达阈值后进入 |
| 路线分歧 | route split     | 共通线结束、进入某条个人线的分叉点     |
| 立绘     | tachie          | 角色的差分表情图                       |
| TRUE END | —               | 某条线的最佳结局                       |
| BAD END  | —               | 某条线的失败结局                       |
