# 故事大纲

## 故事概要

新学期，主人公转入樱丘高中，重逢青梅竹马**心音**，又结识高冷的学生会长**凛**。
一段关于「谁的午后」的选择，将决定这个春天的走向。

## 共通线（Common Route）

### CH01 — 新学期的相遇

- 状态：✅ 完成
- 关键事件：教室重逢心音、走廊偶遇凛
- 分支点：放学后陪谁 → 影响 **心音 / 凛** 的好感度
- 路线锚点：
  - 选「陪心音去社团」→ 倾向 **心音线**（天台场景）
  - 选「帮凛整理学生会」→ 倾向 **凛线**（学生会室场景）

## 个人线（Character Routes）

### 心音线（青梅竹马）

- 核心冲突：习惯了的关系，要不要跨出那一步
- TRUE END：在天台说出口 / GOOD END：维持现状的温柔 / BAD END：错过

### 凛线（学生会长）

- 核心冲突：完美会长的面具下，无人知晓的疲惫
- TRUE END：成为她唯一卸下防备的人 / GOOD END：并肩的战友 / BAD END：永远的距离

## 结局分支

| 路线   | 触发条件               | 结局类型          |
| ------ | ---------------------- | ----------------- |
| 心音线 | 心音好感度最高且达阈值 | TRUE / GOOD / BAD |
| 凛线   | 凛好感度最高且达阈值   | TRUE / GOOD / BAD |
| 共通   | 无人达到阈值           | NORMAL END        |
