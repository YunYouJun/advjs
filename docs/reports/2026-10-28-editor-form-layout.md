# 编辑器表单布局检查报告

日期：2026-10-28。状态：已验证。

范围：桌面 Editor Core 的表单和属性控件，以及 AGUI 共享实现。规范入口为 [AGUI 设计规范](../agui/design.md)，实施记录见 [表单布局统一计划](../plans/2026-10-28-editor-form-layout.md)。本轮调整 17 个共享组件及 29 个 Editor 文件，不改 Studio 与游戏 UI。

## 发现与修复

| 问题 | 统一实现 |
| --- | --- |
| `AGUIProperty` 与 `AGUIFormItem` 分别使用 grid／百分比 flex，标签方向和列间距不同 | `AGUIProperty` 委托公共 `AGUIFormItem`；默认 1:2 列、8px 列间距、标签右对齐，保留原 props 与 label／after-label 插槽 |
| 属性行 4px 外边距叠加父容器 4／8px gap，部分字段则没有统一间距 | 移除行外边距；`AGUIForm` 统一管理 8px 行间距，折叠分组内容也复用它 |
| 顶部标签、帮助文字与窄容器规则被各业务面板重复实现 | 共用顶部标签变体、4px 标签间距与 description 插槽；内容宽度不超过 240px 时自动堆叠 |
| 组合框单独覆盖为 4px 内边距，下拉依赖宿主行高 | 输入／文本域／组合框／下拉共用 8px 水平内边距；单行文字字段为 13px 字号、18px 行高、24px 高度 |
| 数值滑块左右留白不同，向量轨道在极窄容器有固定最小宽度 | 滑块两侧消费公共内边距；向量轨道最小宽度受容器约束，保留数值居中与步进区 |
| 复选框自带外偏移，长说明行高不足 | 移除外边距，说明与复选框相隔 8px，说明允许换行，属性行至少 24px 高 |
| 颜色字段为 16px，拖放字段为 20px，拖放使用固定暗色 | 两者统一 24px 高与字段颜色 token；颜色字段保留系统色盘和焦点，拖放框支持禁用并拒绝禁用投递 |
| 标签 ID 可能落在组件根，未关联真正字段 | 下拉、组合框显式转发到实际字段；自动属性表为下拉、颜色和复选框提供 ID 与标签关联 |

字段内边距、字体／行高、控件内部间距、表单行列间距、顶部标签间距、列定义与工具栏高度均集中在 `packages/gui/client/styles/css-vars.scss`。没有通过调整某一行标签的偏移掩盖问题。

迁移覆盖音频资源及音乐属性、音色设计、对白配音、匿名听审、配音任务、旁白与角色音色、发音词典、混音、供应商面板、角色立绘／关系、JSON Flow、创建项目／章节／场景、在线配置、旧设置与 Codex 工作流。偏好设置继续消费自动属性表，获得同一列宽和窄容器规则。

## 真实界面验证

使用生产构建与真实 Editor Bridge，加载离线听审及供应商测试项目。浏览器插件不可用，因此使用仓库现有 Playwright 直接运行 Chromium 和 WebKit；共享控件小样只用于补充颜色、文件、向量等控件检查，不替代真实编辑器验收。

| 检查 | 结果 |
| --- | --- |
| 实际停靠面板 | 原生拖动 Splitpanes；正常约 841px、窄栏约 321px，未注入宽度覆盖样式 |
| 8 个音频标签 × 正常／窄栏 × 亮／暗主题 | 每个浏览器 32 组；字段内边距均为 8px，单行字段高 24px，纵向相邻字段间距 8px，无字段横向溢出 |
| 更窄布局 | 900px 窗口下主栏约 248px，内部字段自动变为顶部标签、左对齐；底部保存按钮可滚动到达 |
| 在线配置、创建章节、Codex 工作流、角色创建 | 每个浏览器另 4 组，检查中英文标签、帮助关联、编辑／取消、焦点与 Escape |
| 总计 | 每个浏览器 37 组、358 行字段测量，共 74 组；本次最终运行两种浏览器均无页面异常、无 POST 请求 |
| 语言两行精确对齐 | 独立复核正常／窄栏、亮／暗主题的外框与值文字左边缘一致，高度均为 24px |
| 补充共享控件检查 | 两浏览器 × 620／300／160px 窗口 × 亮／暗主题，共 12 组；颜色／文件高度、向量收缩、颜色焦点与禁用态通过 |

供应商 fixture 的合成调用次数为 0。验证前后逐文件 SHA-256 对比相同，项目源码、媒体、配置未被界面检查改写。保存与取消行为另由回归测试覆盖，真实界面检查不触发生成、安装、清理或真实项目写入。
