## 创建前确认名称与位置

欢迎页与系统「新建项目」菜单统一进入 AGUI 创建表单。确认游戏名称、文件夹名称、存储位置和完整路径后，才创建目录并进入项目。游戏名称单独写入游戏配置，支持中文、引号和 `$&`；默认文件夹使用简短英文，同名已存在时建议编号，中文文件夹也受支持。

初始位置为系统 Documents 下的 `advjs-projects`，macOS 通常为 `~/Documents/advjs-projects`。原生文件夹选择器允许更换位置，成功创建后记住该位置，重启后恢复。取消表单不创建目录；取消文件夹选择保留原值。每个窗口捕获自己的创建位置，渲染器不能通过创建参数传入任意目录。已存在的目录、文件与符号链接均拒绝覆盖，非法名称不能提交，创建失败会在表单和全局通知中显示具体原因，保留输入供修改重试。

## 首次欢迎页实现与验收

空窗口显示独立中央欢迎页，包含打开本地项目、示例与空白模板、可搜索的最近项目，以及折叠的其他入口。进入项目后恢复原有停靠工作区；欢迎页不写入项目布局。显式进入空编辑工作区时，左侧仅显示返回欢迎页的短提示。

欢迎页沿用 AGUI 中性背景、紧凑控件与共享蓝色主操作，以示例本身的配图增加视觉层次。参考 [LetsGal Studio 快速开始](https://docs.avg-engine.com/manual/start/quick-start/) 的完整示例／空白模板流程，未引入另一套编辑器配色系统。

首次欢迎页的默认示例「雨夜来信」包含一个人物、两个场景、Markdown 剧本与两张原创本地 SVG。实际预览显示雨夜背景、对白、选项与清晨场景，禁止外网请求时仍能推进至结尾。示例未包含人物立绘、配音或音乐；两个选项展示交互并汇合到同一段后续剧情。空白模板也使用标准 Markdown 项目结构。

原生创建只接收已知模板 ID，通过 macOS 保存对话框选择新目录。目录创建具有排他性，已存在的目录、文件与符号链接均拒绝写入；中文、引号和 `$&` 名称保留正确内容。空窗口直接载入新项目，已有项目时新建另一窗口。已打开的最近项目直接聚焦原窗口。
