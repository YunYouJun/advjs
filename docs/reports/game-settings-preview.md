# 游戏设置页预览验收

日期：2026-10-08。状态：已验证。范围：游戏设置页、默认主题，以及 Editor 内嵌实时预览。

设置页使用「对白、画面、音频、语音」四个页签，保持 16px 正文字号和 18px 页签字号。宽度不足时，顶部工具组与页签分成两行，表单改为单列并将菜单移到底部。亮暗和语言按钮组成「外观与语言」工具组，顶部为关闭按钮预留空间。布局与颜色遵循[游戏 UI 契约](/about/design/game-ui)。

## 问题与修复

实际安装的桌面包仍包含旧版 `text-6xl` 页签及放大的菜单样式，因此仓库中的修复没有作用于原生预览。更新桌面包后，实际项目预览已使用新布局。

原生包验证还发现默认主题的按钮样式通过仓库相对路径引用客户端文件，离开仓库后 Sass 无法加载。引用已改为 `@advjs/client/styles/control-button.scss` 包别名，并重新生成桌面包。

原来的常规设置页同时包含对白、显示与音频选项，内容高度超过常见预览面板。现已按使用目的拆分，默认打开对白页；切换页签保留表单状态，避免重新创建画面控件的局部状态。

## 验证结果

- 18 个相关单元测试通过，覆盖对话控件、操作栏、主题配置和设置控件。
- 5 个浏览器端游戏 UI 测试通过，包括四个分类的内容归属、方向键导航、跨页签保留音量与字体选择，以及缩放容器内的控件可见性。
- 1 个打包后 Electron 原生测试通过：使用临时项目，将真实内嵌预览缩至 320px 宽，逐个切换四个页签，检查字号、溢出、工具组位置与中英文页签完整可见。
- 切换游戏亮暗模式不会改变 Editor 的全局颜色模式；测试项目配置文件保持原样。
- 相关 Vue 组件的类型检查、定向 ESLint 和差异空白检查通过。
- 已备份并更新本机安装的 Editor，重新打开原来的已保存项目，在实际内嵌预览中确认正常字号与顶部工具组。

窄面板和高度不足的面板允许设置内容区滚动，页签、顶部工具组及菜单保持可操作；不将内容压缩到难以阅读的字号。新增原生回归用例位于 `apps/desktop/test/game-settings.spec.ts`。

## 复现命令

先通过 `pnpm desktop:package` 生成桌面包，再运行原生设置页测试：

```bash
ADVJS_DESKTOP_EXECUTABLE="$PWD/apps/desktop/out/ADV.JS Editor-darwin-arm64/ADV.JS Editor.app/Contents/MacOS/advjs-editor" pnpm exec playwright test --config apps/desktop/playwright.config.ts game-settings.spec.ts
```

以上可执行文件路径适用于 macOS arm64，其他平台使用相应打包产物。
