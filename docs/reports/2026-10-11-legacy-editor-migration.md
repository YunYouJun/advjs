## 安全及兼容边界

- 桥接凭据继续使用现有 `history.state` / 桌面有限 preload，不把 token 写入草稿存储
- 草稿恢复为同源浏览器存储中的项目隔离 Markdown/人物草稿；不保存配置/代码内容，不承诺清空存储、换源或原生桌面重启后的持久恢复
- 下载器面向作者主动执行的可信本地项目，不是面向不可信远程请求的 SSRF 或恶意本地文件系统沙箱；不新增网络桥接端点或持久凭据
- MCP app visibility 不等于文件授权。只在既有项目读取边界内提供内容，图片字节放 app metadata；源文的 model-visible 内容仅由明确读取请求返回，并限制长度、总量和错误信息
- 标准 Markdown / 项目数据导出过滤作者字段，保留演员署名与运行时角色字段。直接导入的旧 `.character.ts` / `.scene.ts` 及其依赖仍是浏览器代码，不能放凭据或私密作者资料
- 尝试过的旧 TS 服务端直接求值会破坏 Vite 图片导入与 `new URL(..., import.meta.url)` 语义，因此未采用。完整的旧 TS 作者数据隔离需要独立的 Vite 感知导出管线，不能声称本次已解决
- 没有付费 TTS 调用、模型下载、媒体上传、npm 发布或生产部署
