## 剩余体积与 Git 传输复核

继续检查实际 pack 对象：无损兼容源图约 278 KiB，是最大的单项；约 1.1 MB 的 `pnpm-lock.yaml` 实际只传约 38 KiB 的差异，不删除或压缩锁文件内容。余下大文件均为源码、测试和设计／历史文档。

本机 Git 支持按路径组织打包。本次推送使用 `git -c pack.usePathWalk=true -c pack.useSparse=false push origin dev`，避免普通遍历在文档迁移中携带远端已有内容，并更充分地复用文档差异。文档传输由约 263 KiB 降至 131 KiB，总 pack 约 804 KiB；源文件内容和图标质量保持不变。

将优化后的 thin pack 在独立临时对象目录中补齐基础对象并索引，`verify-pack` 通过；待提交历史要求的 800 个对象全部包含，缺失数为零。选项仅作用于本次命令，不修改全局或仓库 Git 配置，也不改变本机 900 KiB 的大流量确认阈值。原生多平台 CI 仍以实际远端执行结果为准。
