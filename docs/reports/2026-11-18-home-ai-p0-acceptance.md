# 首页无尽列车 P0 验收

日期为 2026-11-18，基线为 `origin/dev` 的 `c35c5045`（PR #84）。本地回放和生产静态构建通过。真实服务商流式直连、30 站抽样和发布用示例旅程待验证。任务和验收范围以 [P0 计划](/plans/2026-10-22-home-ai-mode-p0) 为准。

## 基线与改动

- 基线已包含浏览器 SSE 客户端、剧本校验、一次修正、双语种子与备用段、错误重试、按需加载和示例读取逻辑。首页缺少可重复运行的 Playwright 回放，也没有供访客播放的已审读示例。
- 首页 AI 已按路由选用剧本语言。中文首页原先继承了 `en-US` 的 HTML 语言标记，现为 `zh-CN`，`/en/` 为 `en-US`。
- 首屏守卫现在要求构建产物同时包含应用入口、中文首页和英文首页。三个入口的静态依赖闭包都检查项目编译器、AI、解析器、Shiki、remark 和 unified。

## 实际结果

环境为 macOS arm64、Node 26.13.0、pnpm 12.12.1、Playwright 1.64.0 Chromium。浏览器打开生产构建的 `http://127.0.0.1:3374/` 和 `/en/`，使用 320 × 800 和 1280 × 720 视口。

## 复现

准备工作区依赖和 Chromium 后，从仓库根目录执行。Playwright 启动生产文件预览，并将模型请求发到每个用例独占的回环地址。测试通过显式放行下一批 SSE 数据来观察传输中间状态。

```bash
pnpm docs:build
pnpm exec vitest run tests/unit/ai tests/unit/home
pnpm exec playwright test --config tests/fixtures/home-ai/playwright.config.ts
```

给 Playwright 命令加上 `--reporter=html` 可保留截图附件。附件 `zh-settings-320px`、`zh-ticket-320px` 和 `en-ticket-desktop` 分别显示窄屏设置、中文车票和英文车票。设置面板截图在填写任何输入前捕获。

## 真实服务剩余验收

运行环境未提供已配置的 `DEEPSEEK_API_KEY`，也没有现成的 `AI_API_KEY` 与适用的兼容服务配置。真实浏览器 POST、CORS 和 SSE 返回仍待验证。30 站的 p50/p90、每站用量、修正率和备用段使用率也待采样。

通过已有安全配置注入可用测试凭据后，先从干净的浏览器会话执行一次连接测试和一次生成，确认 POST 返回并在传输中显示剧本。示例生成使用同一套安全配置运行以下命令，审读旅程并验证无密钥播放后，再将示例交付首页。

```bash
pnpm tsx scripts/home-ai-sample.ts zh 6
pnpm tsx scripts/home-ai-sample.ts en 6
```
