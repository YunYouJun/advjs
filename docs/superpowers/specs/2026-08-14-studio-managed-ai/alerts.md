# 托管 AI 告警清单

首期阈值在 staging 以低流量校准；以下硬安全条件不依赖客户端发布。

| 信号           | 初始触发建议                                       | 自动动作                           | 人工动作                                    |
| -------------- | -------------------------------------------------- | ---------------------------------- | ------------------------------------------- |
| 平台实际成本   | 达到日上限 ¥50，或 80% 预警                        | 达上限拒绝新任务                   | 核对价格快照、异常 attempt 与预算流水       |
| 对账队列       | 任一任务超过 15 分钟；队列连续增长                 | 保持相关用户预占，禁止重复模型调用 | 按对账 runbook 逐 taskId 处理               |
| 结算/释放失败  | 5 分钟内连续 3 次或错误率 >1%                      | 建议全局 kill switch               | 检查 account-api、幂等重试和事务状态        |
| 模型不确定结果 | 任何 `MODEL_EXECUTION_UNCERTAIN`                   | 任务进入对账                       | 核对供应商 usage/requestId，不猜金额        |
| SSE 恢复失败   | 5 分钟错误率 >5%                                   | 客户端退回快照轮询/稳定错误        | 检查 cursor、网关超时与实例健康             |
| 解析失败       | 15 分钟 >10% 或同能力连续 5 次                     | 关闭该 capability                  | 检查模型/prompt/parser 版本，不展示原始正文 |
| 安全阻止       | 短时异常增长或规则版本突变                         | 可关闭单能力                       | 最小化审核稳定原因码，限制敏感正文访问      |
| 认证/CORS 拒绝 | 合法 Origin 失败 >1%；未知 Origin 突增             | 保持 fail closed                   | 核对 SSO audience、Origin 与时钟偏差        |
| 单用户限额异常 | 出现并发 activeTask 或超过日限额                   | 拒绝新任务                         | 检查账户事务与过期锁 sweeper                |
| 数据泄露探测   | 任一密钥、token、prompt/正文进入公开日志/SSE/Admin | 立即 kill switch，轮换凭证         | 启动安全事故与回滚流程                      |

告警事件最小字段：时间、环境、版本、taskId/requestId（如适用）、能力、稳定错误码和聚合金额；不得包含创作正文、完整 prompt、access token、API key 或供应商原始响应。
