# UI 设计入口

ADV.JS 的界面分为面向玩家的游戏 UI 与面向作者的创作工具 UI。详细职责、主题和样式归属见 [统一设计体系](./design-system)。

- [游戏 UI 规范](./game-ui)：默认界面、主题配置、组件覆盖与嵌入预览。
- [AGUI 桌面编辑器规范](/agui/design)：紧凑控件、停靠面板和编辑器主题。
- [Studio 设计规范](./studio-design)：移动创作布局与品牌视觉。
- [场景演出与素材](/guide/runtime/presentation)：2D/3D 内容、立绘、CG 与音频的运行时行为。

游戏的美术风格由主题决定；编辑器工具保持自己的设计规范。
