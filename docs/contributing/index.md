# 参与贡献

::: tip
很高兴你愿意打开这个页面。

如果你觉得这个项目不错，并且想要参与进来为其贡献。
你可以加入右上角的 Discord 进行交流。

接下来，我将简要说明一下贡献规范。
:::

## 贡献文档

> 出于便捷，目前优先以中文文档为主。
> 未来，我们希望可以借助 AI 自动翻译多语言文档。

如果您想要对文档进行贡献，请先阅读 [文档写作指南](/contributing/writing-guide)。

## 贡献代码

先按[环境配置](/about/env)从干净仓库启动 Demo 或 Editor，再用[贡献者调试指南](/contributing/debugging)设置断点并运行最小测试。提交代码时请遵循[开发规范](/about/dev/standard)。

维护发版说明时参考 [AI 双语 Release Notes](/contributing/release-notes)，支持正式主／次版本自动摘要、语言选择与补丁版手动补生成。

## 贡献生态

如果您想要制作一些示例和教程，这是相当欢迎的。

您可以提交相关链接到 [资源](/resources/) 页面中。
