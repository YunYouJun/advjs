# Editor 音频工作区视觉精修

- 日期：2026-10-27。
- 状态：已完成。
- 范围：官方插件目录、批量配音、试听播放器，以及这些界面实际消费的 AGUI token 和组件。

## 设计方向

沿用 AGUI 的中性桌面工作台，通过成组留白、清晰字重、安静的边界与真实状态反馈改善层级。参考苹果专业创作工具的细节，不改变停靠区域、全局控件密度或游戏主题。继续使用现有亮色背景 `#f1f1f1`、内容 `#ffffff`、分隔 `#c7c7c7`、强调 `#35639a`，暗色背景 `#1a1a1a` 与内容 `#383838`；业务组件只使用语义变量。

字体继承宿主系统无衬线栈；控件使用 12–13px，分组标题 14px，配音正文使用 14px 与较宽行距。间距采用 4／8／12／16px，基础控件保留 3px 圆角，内容分组可使用 6px。短过渡仅反馈选择、复制和播放操作，尊重减少动态效果设置。

插件目录：宽面板左侧提供可键盘选择的紧凑列表，右侧展示当前插件的能力、平台、状态与接入说明；窄面板上下排列。批量配音依实际顺序分为选择范围、审核预算、生成进度。播放器突出当前试听与时间轴，技术记录按需展开。

## 组件职责

- `AGUISection`：提供具有可访问标题的内容分组与 actions／footer 插槽，消费共享尺寸、间距和表面规则。
- `AGUICodeBlock`：展示可选择的原始代码与真实复制反馈，处理失败、内容变化、迟到与卸载，不渲染任意 HTML。
- `AGUITag`：保留旧 theme／close API，补充具有文字的语义状态 tone；目录、任务与播放器复用。
- `AGUISlider`：保留现有默认属性控件，提供媒体轨道变体，原有键盘、禁用与事件协议不变。
- 插件容器仅组合选择与状态；列表和详情分别呈现。任务容器组合范围、预算、审核与队列子组件，保留现有宿主行为。

## 验收

1. 目录选择、键盘焦点、源码复制和显式健康检测可用，不隐式安装、下载或合成。
2. 范围、预算、批次、取消／恢复／重试、审核选用等既有语义不变。
3. 播放器使用真实媒体时钟，定位与逐字高亮同步，源切换和离开时停止。
4. 共享 token 在亮暗主题均有值；现有 AGUI 默认控件不被全局重置，新组件保留可访问名称与可见焦点。
5. 正常与 320px 面板、亮暗主题、中文／英文和减少动态效果通过浏览器检查；截图与临时验收数据保存在项目外，结束后回收可重建产物。

## 实施与验证记录

- 共享层新增 Section、CodeBlock、Tag tone、媒体滑块变体，以及 opt-in 间距、字号、行高、圆角和短动效 token；原控件默认形状和尺寸保持原有契约。
- 官方目录改为选择列表与单个详情，支持方向键、Home／End 与真实复制。批量任务分为范围、预算与进度，长结果按需渲染，真实生成状态、阻断原因和任务定位信息保留在可访问的位置。
- 试听正文与播放器合并，同文去重、异文审核保留。长文在独立阅读区内跟随实际高亮字滚动，不滚动整个工作区。
- 69 个相关单元测试文件共 668 项通过；5 条 Chromium 真实 Editor 流程通过；根项目 ESLint、vue-tsc 和 Nuxt Editor 生产构建通过。
- 实际 Node CLI 打开已有 Breeze 项目，模型状态、原有长配音播放、跳转、高亮跟随、复制与键盘选择通过；亮暗、320px、英文目录、200% 缩放和减少动态效果已检查，页面无异常。素材、账本、音色库与配置前后哈希一致，新增界面验收未调用模型合成。
- 编译宿主的两句音频校验与登记实测约 6.5 秒；E2E 对该异步完成步骤使用 30 秒上限，保留生成次数、登记结果和已选配音不被覆盖的断言。
