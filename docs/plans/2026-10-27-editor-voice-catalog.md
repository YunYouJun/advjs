# Editor 批量配音与官方插件目录

- 日期：2026-10-27。
- 状态：实现与本机验收完成。
- 前置：本地 Breeze、参考克隆、可选清理和逐字高亮已独立提交；本计划只补齐批量入口与官方发现目录。

## 实施边界

从最新远端 `dev` 建立独立分支，迁移语音改动时排除原工作区其他任务的提交、暂存内容和修改。保留原工作区，后续改动在隔离工作树提交推送。

Editor 复用 Studio 的章节和缺失／过期筛选语义、共享计划与 Runner。总范围只审核一次预算，超过 200 句时在同一个持久任务内按窗口推进，继续使用已有并发、指纹复用、取消、恢复和失败处理；生成结果仍需显式选用。

官方目录复用 Editor 插件管理面板，首批收录 Breeze、Qwen 与 OpenAI 语音适配器。元数据描述能力、平台、资源要求、源码安装和配置说明；读取目录不执行推理、安装或模型下载。状态检测由用户显式触发，沿用可信宿主的供应商注册与诊断能力，区分未配置、停用、无法诊断、未就绪与就绪。不把适配器冒充 UI 扩展，不宣称尚未发布的 npm 包可直接安装。

## 验收条件

1. 远端分支仅含本次语音功能和本计划改动，基于最新远端基线；原工作区不被重置或暂存。
2. Editor 支持章节和全部／缺失／过期范围，角色入口仍限制当前角色；宿主依据真实输入指纹决定范围。
3. 超过 200 句自动分批，预算覆盖全部范围，失败或未知请求停止后续批次；恢复不重复已完成生成。
4. 官方插件目录可展示能力、平台、安装与配置说明，真实状态检测不触发合成或环境安装；切换项目和隐藏时取消界面请求。
5. 相关单元、类型、构建与文档检查通过；浏览器检查正常与窄面板、状态检测、筛选、预算审核和任务进度，并留存截图于项目外。
6. 临时项目、日志与可重建中间产物回收；不删除用户参考录音、已完成配音或在用模型。
