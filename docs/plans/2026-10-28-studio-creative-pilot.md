## 模型、价格与版本依据

复用已登记的 `custom-deepseek-open/deepseek-v4-flash`，经现有 CloudBase 服务端 SDK 调用官方 DeepSeek 接口，不修改模型组。当前[官方标注](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)为 `DeepSeek-V4.1-Flash-1017`；请求别名不能证明权重不变。试跑保留供应商响应的实际 `model`、`system_fingerprint`、请求 ID 和用量，所有模式共用同一观察器。信息缺失、同一调用内不一致或后端变化会使样本无效，并禁止后续生成；已确认用量仍保留，不能改成零费用。

使用 2026-10-28 重新核对的人民币分时费率：每百万输入 token 空闲／高峰为 1／2 元，缓存命中为 0.02／0.04 元，输出（包含推理）为 4／8 元。预占覆盖峰值，实际计算按派发时间、周末及已核对的节假日规则选择费率；不使用现网旧应用策略的价格。这里的成本来自供应商用量与冻结费率计算，最终仍须与实际回执核对。

纯文本输入上界依据官方 checkpoint `1bae0e1088993b9b82de08f59de5be5a34e42170` 的编码源码和 tokenizer：无文本归一化扩张，256 个字节基础符号完整，BPE 不增加前后缀；角色包装与思考提示单独预留固定 512 token 和每条消息 128 token。3,063 个角色序列／Unicode 输入已核对。只接受纯文本三种角色，不发送原生工具 schema、图片、额外消息字段或响应 schema。此为源码审计，真实托管端是否遵守上界仍须由首批响应核对，不能以免费预检认证。

执行前固定实际 Runtime 导出、SDK 版本信息、锁文件、绑定脚本和来源审计指纹；A／B／C 的描述必须一致。本轮准备的配置有效期为 24 小时；过期先免费刷新与预检，不扩大既有授权范围或金额。模型版本、任务或费用上限发生实质变化时另行确认。
