# Editor 世界观、场景与章节创建

日期：2026-10-09。状态：工作区实现与本地验收通过。范围：补齐 Web 菜单与桌面原生「故事 → 创建」中的三个入口，沿用标准 Markdown 项目与 ProjectWorkspace。验证见[验收记录](../reports/editor-content-creation)。

## 实现职责

- 内容规划器生成相对路径、Markdown 模板和带预期内容的文件变更。遵循项目内容根目录，保留显式章节列表、原入口和未知配置字段。
- 创建状态层共用核心插件命令，处理草稿、重复提交、写入失败、创建后打开失败的重试及项目切换。
- AGUI 对话框只呈现名称、标识符、真实文件路径和错误；成功后打开文件源码。公共插件仍不获得项目写入服务。
- 原生菜单仅增加三个有限动作，转发到同一核心插件命令；创建不增加原生文件系统或任意脚本接口。

## 验收

- [x] 世界观使用内容根目录下的 `world.md`；已存在时打开原文件，不覆盖。
- [x] 场景与章节使用 `.md` 和 `.adv.md`，模板可由现有解析器编译；拒绝非法名称、路径、重复 ID 和大小写等效文件。
- [x] 自定义内容根目录与显式章节列表正确；增加章节后原章节与游戏入口不变，配置额外字段保留。
- [x] 浏览器、本地桥接使用同一写入合同，预期内容冲突时报错；失败可重试。已有草稿不丢失，取消不写入。
- [x] 写入成功后打开失败只重试打开；切换项目后迟到结果不打开旧文件或更新新表单。
- [x] 无项目、恢复中与不支持的项目模式禁用核心命令；原生菜单在无项目时禁用。中英文、键盘、亮暗主题与 320px 宽度可用。
- [x] 原生创建动作可从角色路由打开对话框，成功后回到文件源码；角色表单草稿也会阻止创建与跳转。
- [x] 通过定向单测、真实 Chromium 创建流程、Editor 类型检查与构建、改动范围 ESLint 和文档检查。
