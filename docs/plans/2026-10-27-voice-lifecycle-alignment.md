# 语音供应商资源清理与音文同步

- 日期：2026-10-27。
- 状态：已完成；验证见[验收记录](../reports/2026-10-27-voice-lifecycle-alignment.md)。
- 范围：通用作者语音协议、Breeze 本地部署、Editor 管理界面、候选试听与玩家逐字高亮。

## 复用与实现

复用既有供应商注册、原生素材、审核计划、播放后端和 `PrintWords`。音文对齐采用当前 MLX-Audio 已包含的 Qwen3-ForcedAligner，中文按字、英文按词输出真实时间戳，不按音频总时长平分。模型固定修订，离线执行；对齐数据绑定实际音频哈希和准确文本，改词、换音频后失效。

清理使用供应商可选维护接口与可信宿主登记的资源清单。缓存、环境、模型分别选择，显示空间、共享关系和保护范围；预览计划与执行前重检，拒绝路径越界、链接替换、在用或已变化资源。先停用供应商并停止明确受管理的服务，再执行选择的资源清理；不隐式运行包管理器或改写可执行项目配置，显示项目包移除指引。参考录音、已登记音频、音色库、对白账本及完成的生成结果不纳入默认缓存清理。

## 验收

1. 清理只处理可信清单内且作者选中的类别；缺失、不受管理、共享未确认和计划过期均可识别。
2. 以独占临时目录验证真实删除与空间变化，保护参考和已生成音频；不实际卸载正在展示的 Breeze 模型。
3. 已停用供应商不能执行新生成；已有配音仍可试听与播放，其他供应商继续可用。
4. 对齐器复用现有 Python 环境，实际运行一次中文音频；持久化并校验字词范围、时间、文本与音频身份。
5. 候选试听和玩家随真实播放位置更新高亮，暂停、定位、切句、跳转与停止正确清除或恢复；缺少对齐的旧音频保持正常播放。
6. 保留词条交互、原有打字机与主题边界；正常和窄面板、玩家截图与真实浏览器交互通过。
7. 单元、相关回归、构建、类型与文档检查通过，运行证据写入验收记录；临时实验产物及时回收。
