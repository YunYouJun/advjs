# Editor 共享微动效实施计划

- 日期：2026-10-27。
- 状态：已完成；实现、验收证据与实际限制见[验证报告](/reports/2026-10-27-editor-motion)。
- 范围：`packages/gui/` 的共享动效 token、局部浮层、模态对话框、通知及已有控件过渡；以 Editor 音量浮层和偏好设置作为真实消费场景。
- 实现基线：`adefdfc0019010fc36882ef7a94664e123d5f509`，已包含系统 UI 字体、按需音量浮层与共享 AGUI 控件。

## 目标与约束

通过短促、可中断的操作反馈改善编辑器质感。借鉴 Apple 专业创作工具的自然开合与减速，继续遵循 [AGUI 规范](/agui/design) 的中性灰、紧凑控件与停靠工作区；长期规则维护在该规范，本文只维护本次实施范围和验收标准。参考 [Apple Motion 指南](https://developer.apple.com/design/human-interface-guidelines/motion) 的目的性、及时反馈和减少动态效果原则。

复用现有 Vue、Reka UI 的状态、Presence、Portal、定位和焦点语义，以及 CSS 动画／过渡。按需补足共享样式，不新增动效运行时依赖。共享规则限定于 AGUI 控件，不向 `html`、`body`、通配选择器或内嵌游戏注入全局动画。

面板拖动、音量／进度滑块和数值调整继续即时跟手；逐字高亮继续由真实音频时钟驱动。布局密度、字体、主题、项目读写和配音生成语义保持既有合同。弹跳、循环装饰、整屏进场、卡片悬浮和玻璃模糊均不属于本轮范围。

## 实施顺序

### 1. 统一共享动效契约

- 在 `packages/gui/client/styles/css-vars.scss` 集中定义本轮需要的时长和缓动。状态反馈沿用约 `120ms`；局部浮层入场建议 `120–160ms`；Dialog 建议 `160–200ms`；退出可使用更短时长。具体值经真实界面确认后写入 AGUI 规范，不称为 Apple 系统的精确参数。
- 对本轮涉及的按钮、字段、Switch、Accordion 和浮层消除重复的固定时长／缓动，避免扩展为无关 UI 重构。
- `prefers-reduced-motion: reduce` 下移除位移、缩放与非必要动画／过渡。对 Presence 依赖的 CSS 动画明确处理 `animation: none`，验证即时卸载，不能仅假定 `0ms` 就覆盖全部行为。

### 2. 补齐局部浮层与对话框

- Popover、Select、DropdownMenu、Menubar 的内容根消费同一套轻量浮层规则；复用 Reka `data-state`、方向与变换原点。采用淡入淡出，位移控制在约 `2–4px`；缩放与位移按场景选取，避免叠加过多效果。
- 优先确认音量 Popover 与偏好设置 Select，随后覆盖同一共享原语的菜单和子菜单。Portal 内容必须得到实际样式；碰撞翻转后仍沿正确方向出现，位置更新不重新触发入场。
- Dialog 遮罩淡入，内容可采用最大约 `0.98 → 1` 的轻微缩放。保留既有居中 `translate(-50%, -50%)`，避免 keyframes 覆盖定位 transform。
- 验证开启即可操作、快速连续开关可中断、退出后 DOM 能及时移除。复用 Reka Presence，不用业务层计时器延迟交互或重复维护 open 状态。
- 关闭态、关闭后和切换面板后不得留下可点击或拦截指针的透明浮层。保留 Escape、外点关闭、焦点捕获和合理的焦点返回。

### 3. 统一通知与既有控件反馈

- Toast 保留现有滑动关闭和可操作内容；入退场与滑动状态消费共享值，减少动态效果时即时呈现状态并正常关闭。当前 `update:open=false` 会立即移除列表项，需检查真实退场生命周期，覆盖自动超时、手动关闭、滑动关闭与超过数量上限后的替换；不能只补 CSS 就宣称退场完成。
- 按钮、字段、Switch、Accordion 的既有反馈统一时长／缓动，不对拖动值、进度、滑轨或逐字文本增加滞后。
- 音频／任务状态继续使用已有图标、文字和 Tag；本轮不增加每字动画或新的播放器状态机。确有突变时仅在共享呈现层补充短促颜色／透明度反馈，不改变内容宽高。

### 4. 验证、记录与交付

- 更新 [AGUI 动画规则](/agui/design)，记录 token、适用场景、减少动态效果和定位／Presence 边界；保持本计划为任务验收入口。
- 运行受影响组件的现有语义测试；最低入口为 `tests/unit/gui/agui-popover.test.ts`、`tests/unit/gui/agui-controls.test.ts`、`tests/unit/editor/audio-volume.test.ts`。仅对真实行为缺口增加回归；涉及播放呈现时按需补跑 `audio-player.test.ts` 与 `voice-transcript.test.ts`，不无条件扩大为全量音频测试。
- 动画实际发生、退出移除和 reduced-motion 用浏览器验证，不以源码字符串或 jsdom 的 CSS 存在断言代替。禁用动画的截图只能证明终态；Presence 不得依赖一定会触发的动画结束事件控制业务状态，上层布局切换或卸载时优先安全即时关闭。
- 完成相关 lint、类型检查、GUI 与 Editor Core 构建；共享样式影响 VRM 时补充其构建和启动检查。文档运行 `pnpm docs:check` 和 `pnpm docs:build`，区分既有失败与本轮新增问题。
- 在 `docs/reports/` 写入实际验证结果并更新本计划状态。截图、动效采样、日志和一次性脚本保存在项目外；报告链接证据，不将临时浏览器文件提交仓库。
- 构建／验收使用任务独占临时目录，结束后回收本轮可重建中间产物并记录空间变化，保留仍需使用的依赖、增量缓存和不可替代素材。
- 只提交本轮计划、规范、共享动效和必要回归，使用 Conventional Commits。实施新会话处理代码提交；合并和发布不属于本轮范围。

## 验收标准

1. 音量 Popover、Select、菜单／子菜单、Dialog、Toast 在真实 Editor 中有一致且短促的开合反馈；入退场均实际生效，操作无需等待动画完成。
2. 深／浅主题、中文／英文、常规与 `320px` 面板、靠近视口边缘和碰撞翻转时，浮层无位置跳变、裁切、横向溢出或额外页面滚动。Dialog 保持居中，Portal 的字体、背景、圆角与阴影不回退。
3. Escape、外点关闭、Tab／方向键、焦点捕获与返回仍正确；快速重复开关、切换面板和卸载后不残留透明遮挡、计时器或卡住的 Presence。
4. 浏览器模拟减少动态效果，并在运行中切换该偏好：非必要位移、缩放和循环效果停止，菜单、Dialog 和 Toast 仍可即时开关，状态不丢失。
5. 音量和进度调整即时生效，播放／暂停与逐字高亮维持真实时钟同步；Splitpanes 尺寸拖动仍即时。实际项目内容、音色参考录音、已生成音频和模型环境不因界面验收发生变化，不隐式合成或下载模型。
6. 浏览器记录显示正常模式有预期的中间帧及结束状态，减少动态效果时有即时状态与正常卸载；保留深浅主题／窄面板截图及必要的动效采样，页面无新增异常。
7. 受影响的交互回归、lint、类型检查和相关构建通过；失败如属既有问题需提供可复现证据。工作区只包含本轮相关改动，计划状态依据实际验收更新。

本轮使用独立分支 `codex/editor-motion`，保留语音与字体基线。工作树被外部归档后，从仅包含本计划与索引改动的快照完整恢复；默认项目目录未编辑。

已实现共享时长与缓动、浮层／Dialog 入退场、Toast 内容生命周期与减少动态效果；实际集成发现全局 Dialog 的父级 `v-if` 会跳过退场，因此增加 `AELazyDialog` 回收边界，并修复异步打开与切换语言后的返回焦点。运行中切换减少动态效果采用已关闭 Presence 的重建边界，不依赖首帧前一定会发生的动画事件。
