# Editor 中央欢迎页与示例项目

日期：2026-10-07。状态：实现与本机安装完成，验收通过。范围：桌面 Editor 空窗口、项目模板与原生创建流程。验证记录见 [Editor 欢迎页报告](../reports/editor-welcome.md)。

空窗口显示独立中央欢迎页，打开项目后恢复原有停靠工作区，不修改已保存的面板比例。默认入门示例「你好，ADV.JS」复用 `demo/starter` 的现有剧本、人物与本地素材，以及 Markdown 创作与空白模板。常规入口保留中性 AGUI 控件，示例主操作使用共享蓝色；模板配图属于作品素材。早期实现的「雨夜来信」仍可通过原生新建菜单选择，已创建的项目不自动改写。

## 组件与数据责任

- `pages/index.vue`：组合欢迎页与编辑工作区，依据项目和临时显示状态选择。
- `AEOpenProject`：协调打开、创建、恢复与最近项目；中央布局和原 Web 面板共享入口。
- `AEProjectTemplates`：展示模板，接收禁用状态，通过 `create` 事件提交模板 ID。
- `useCreateProject`：分别调用有限桌面 API 与浏览器文件接口，汇报创建状态和错误。
- `AECreateProjectDialog` 与 `useDesktopProjectCreation`：所有桌面新建入口共用名称、文件夹与存储位置表单，提交前显示完整路径。
- 桌面宿主：只接收已知模板 ID 和经过校验的名称；父目录由宿主默认位置或原生目录选择器确定，不接受渲染器指定任意写入路径。创建新目录，不覆盖现有项目；继续使用现有多窗口打开逻辑。
- 模板清单：构建时从 Editor 模板定义生成，原生宿主与浏览器使用同一份内容。
- 入门内容：`demo/starter` 保存唯一剧本与游戏数据；Editor 模板只转换目录结构。小云头像复用 `demo/love` 的本地 WebP，原生与浏览器创建流程都写入原始二进制图片。
- 对白布局：沿用游戏 UI 契约，姓名以正文 90% 字号与半粗体显示；无头像或图片失败时姓名在正文上方，窄屏头像与姓名并排。

## 验收

1. 空窗口只出现一份中央欢迎页；打开和关闭项目正确切换，不重写项目布局。
2. 示例包含人物头像、场景、剧本及本地资源，编译无错误，真实桌面预览可推进分支、变量动作与条件文本；剧本和头像与现有 Starter 来源一致。
3. 创建前分别确认游戏显示名、文件夹名和存储位置；默认文档目录下的 `advjs-projects`，记住上次成功创建的位置，同名路径建议数字后缀。游戏显示名支持中文与引号，文件夹校验跨平台非法名称；取消无项目写入，未知模板、任意父路径及已存在目录被拒绝。
4. 已有项目中新建时打开新窗口；新项目进入最近项目列表。
5. 1440×900、320px 宽内容区域、亮暗模式、中英标签与键盘焦点截图检查。
6. 对白姓名随阅读字号缩放；关闭、未配置及加载失败的头像正确回退。宽屏与 390px 窄屏检查姓名对齐、长姓名换行及游戏主题 token。

参考 [LetsGal Studio 快速开始](https://docs.avg-engine.com/manual/start/quick-start/) 的完整示例／空白模板与创建后运行流程；Editor 的视觉仍遵循 [AGUI 规范](../agui/design.md)。实际验证记录到 `docs/reports/editor-welcome.md`。
