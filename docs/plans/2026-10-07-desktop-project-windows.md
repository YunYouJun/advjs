# 桌面多项目窗口与状态反馈

- 日期：2026-10-07
- 状态：已实现并通过本地与打包版回归；macOS 安装已更新
- 验证：[多项目窗口与状态反馈验证记录](../reports/desktop-project-windows.md)。
- 范围：Electron 宿主、Editor 外壳与桌面回归；不改变游戏运行时与 Studio。

## 目标与验收

1. 单主进程管理多个编辑窗口，每个窗口独立持有项目服务、凭据、草稿状态、构建任务和预览；关闭一个窗口不影响其他窗口。
2. 空窗口直接打开项目；已有项目默认在新窗口打开，菜单及项目切换器提供「在当前窗口打开」。同一规范路径（包含符号链接别名）只保留一个可写会话，重复打开聚焦已有窗口。
3. 项目切换器同时显示已打开与最近使用的项目，并同步窗口打开、关闭与历史变化；菜单操作作用于当前编辑窗口。
4. 项目名称放在原生标题栏。底部状态栏显示连接、未保存内容、当前文件／编辑位置及构建状态；错误与日志不占据顶部工作区。
5. 失败通过全局通知显示，含「复制信息给 AI」及日志查看入口；报告包含项目、环境、错误和日志并继续脱敏。通知关闭后仍能从状态栏或控制台找到错误。
6. 每个规范项目路径独立持久化面板布局、激活面板、打开文件与光标／滚动位置。替换、关闭、重载和退出处理未保存内容；保存失败或取消时保留窗口与草稿。

## 实施划分

- 宿主：窗口会话封装、统一 IPC 调度、单实例与路径去重、活动窗口菜单、按项目保存 UI 状态。
- 外壳：应用级通知宿主、可复制错误通知、底部状态栏、项目切换器；删除顶部桌面状态／错误栏。
- 状态恢复：启动阶段恢复布局与打开文件，编辑器记录位置，关闭前明确等待状态落盘。
- 验证：真实 Electron 多窗口、重复路径、关闭／退出取消、IPC 隔离、重启恢复、通知复制与任务隔离；正常／窄面板及亮暗截图。记录实际结果后更新本文状态与桌面指南。
