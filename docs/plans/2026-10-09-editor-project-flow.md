# Editor 真实项目分支图与源码定位

日期：2026-10-09。状态：已实现并通过本地验收，尚未发布。范围：Editor 的只读剧情流程图、保存快照的源码定位、静态可达性与编译诊断；遵循 [AGUI 规范](/agui/design)。使用说明见 [剧本编辑](/guide/editor/script#查看项目分支图与定位源码)。

## 实现职责

- 纯投影以当前项目的 RuntimeProgram 为节点与边的权威，解析章节源文件仅用于还原位置，不执行剧情或宿主插件。
- 章节、剧情与独立选项节点显示真实关系，支持跨章节跳转、条件分支、循环与明确结局；稳定标识随项目更新保持一致。
- Flow 状态层负责异步投影、项目切换隔离、章节筛选和布局。图视图负责渲染与隐藏恢复；节点和诊断组件只发送源码定位请求。
- 源码导航复用项目文件打开和 Monaco 绑定，校验保存快照与当前文件，阻止未保存草稿、项目切换与销毁后的迟到定位。
- 静态可达性表示从配置入口出发的可能路径，不代表试玩覆盖。宿主或插件动态导航保留未知状态；编译失败时显示可确认的章节与诊断。

## 章节概览、段落聚合与增量缓存

2026-10-09。状态：已实现并通过本地验收，尚未发布。范围：流程图的分层呈现与大量节点性能；沿用原 RuntimeProgram、源文件和跳转地址，聚合不写回剧情结构。

### 呈现与缓存职责

- `project-flow-view.ts` 提供章节概览 → 段落 → 剧情详情。段落使用一／二级标题、场景和文件备用边界，选项跟随所属剧情；直接查看整章或全部剧情仍可用。
- 所有层级每页至多 200 个基础节点、另加最多 40 个边界门户。高密视图至多绘制 600 条连接，超出连接收进独立汇总节点；全部原始路线仍可在每页 50 条的明细中定位源码或展开准确目标。汇总虚线没有箭头，不表示新的剧情循环。诊断列表同样按每组 50 条呈现。
- 跨章节、跨段和跨页门户保留准确目标地址。章节概览合并连线时，明细分别保留每条选择的条件、来源行号和章内目标；不会把跳到章中间改成章节入口。
- 源码位置构建器按工作区保存当前章节索引，以文件路径、顺序和内容决定复用。只改一章时仅重建该章位置索引；剧情关系、诊断和静态可达性每次刷新重新计算。项目切换、关闭和旧异步解析不会污染新缓存。
- 完整图保存在浅响应式状态中，renderer 只接收当前页。图索引与视图缓存按图生命周期管理，保留最多 24 个投影视图；状态保存最多 32 个视图的位置、方向和 viewport；布局缓存最多 48 份拓扑／尺寸／方向结果。
- 首次只排列实际挂载并测量的当前视图，返回复用位置与取景。可见标签、数量或诊断计数改变时重新取景，内部剧情变更仍更新精确路由数据。自动排版可强制重算；超长直线、复杂连线、较多回跳和超过布局预算的导入图使用无递归网格兜底。200 节点的线性页面保持可取景的宽高比例，跨页展开按钮可以正常鼠标点击。
- 少量节点的自动取景限制放大倍数，并隐藏不必要的缩略图，保证鼠标能直接点击展开按钮；取景给底部控件留出 40px，320px 亮暗面板的节点不被控件遮挡。迟到的旧 renderer viewport 不会覆盖新视图，隐藏面板时不执行迟到取景。
