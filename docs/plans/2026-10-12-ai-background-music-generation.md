# 音乐创作与背景音乐／主题曲工作流

> 日期：2026-10-12。状态：本地流程已实现并验收。范围：创作方案交接、用户自创或借助 AI 创作后的文件导入、试听采用、章节／Flow 绑定与游戏播放；自动音乐生成适配器另列后续任务。实际音乐听感与第二台设备仍待验收。

[Issue #18](https://github.com/YunYouJun/advjs/issues/18) 同时提出台词语音和背景音乐。角色音色与对白沿用[音频主计划](./2026-08-12-audio-system-implementation)。本页是独立音乐任务的权威入口；根据作者后续要求，首期从供应商生成执行调整为打通创作与使用流程，具体音乐由用户创作。

## 目标与边界

Editor 和 Studio 共享 JSON 音乐资料：背景音乐、主题曲、OP、ED 和插曲的用途、创作方案、来源、许可与试听状态。用户可以在 DAW 自创、委托创作或使用 AI。导入真实文件并试听后，显式采用，再在章节／Flow 中选择绑定位置。两端写入唯一 Asset Catalog，普通游戏构建使用已有 AudioEngine 的 music 总线播放。

主题曲可包含用户创作的歌词和歌唱音频；用途是作者资料，不增加 Runtime 总线，不交给对白 TTS，也不自动在标题页播放。提示中的时长、节奏、器乐与循环要求只是创作意图，实际输出和循环接缝需试听确认。导入、采用和剧情绑定分别执行。

Suno 首期采用[官方创作入口](https://suno.com/create)、可复制的创作方案与 JSON 导出，以及从官方渠道下载后的本地文件回流。[官方下载指南](https://help.suno.com/en/articles/2409921)说明了下载入口，格式能力以[官方说明](https://help.suno.com/en/articles/13926081)为准。2026-10-12 核查未找到可核验的官方公开音乐生成 API；已公开的 [Suno Credentials API](https://about.suno.com/suno-credentials)用于来源凭证检测，不是音乐生成。当前实现不接入第三方同名接口、不抓取试听流、不代替用户支付或调用收费生成。

## 实施任务

1. 在共享类型和 Catalog 解析器定义版本化音乐资料，保持 `type: audio`、`kind: bgm` 与稳定 asset ID。来源页面不参与媒体解析，不另建音乐数据库或写入 Voice Ledger。
2. 两端提供按需展开的创作方案：用途、描述、情绪／风格、目标时长、节奏、器乐和循环意图、补充说明；复用同一 JSON 导出和文本交接格式。
3. 复用现有真实文件导入、媒体哈希、CAS 和失败回滚，保存方案、来源及许可。试听使用现有宿主；项目切换、关闭和迟到媒体读取不得恢复旧播放。
4. 显式试听采用绑定不可变媒体 SHA。修改影响审核的音乐资料使采用状态过期；标题等展示资料不撤销既有判断。采用不自动写入剧情，也不取代真人音质评价。
5. 从资源库进入已有章节／Flow 音频操作，作者选择位置后确认。复用 BGM 的 loop、gain 与 fade，不新增播放器、标题页协议或生成注册表。
6. 验证两端导入 → 试听采用 → 显式绑定 → 普通 JSON Flow 构建／播放，核对字节、身份、未引用资源与作者资料排除、普通和窄屏布局；报告分别记录自动化证据与真人听审。

## 验收标准

- Editor／Studio 能读写同一份音乐资料和方案导出；既有无音乐资料的 BGM 继续兼容。
- 打开方案、复制／导出、试听和进入 Suno 不调用音乐生成、不自动写入剧情。
- 采用核验实际媒体字节与 SHA，过期 revision、许可或母版变更被拒绝；旧素材与绑定保留供作者明确处理。
- 背景音乐、主题曲、OP／ED 和插曲使用同一 canonical BGM 操作和 music 总线。来源网页不可成为播放器媒体地址。
- 普通导出仅收集被剧情引用的音频，作者方案、私有来源资料、未引用候选和 TTS 配置不进入玩家包。
- 本地流程不收费、不上传 COS、不要求 CFS 或常驻独立音乐服务。实际 AI 生成、音乐质量和第二台设备不以本地波形／浏览器测试代替验收。

## 后续自动生成适配器

独立跟踪：[Issue #64：接入正式音乐生成供应商与结果回流](https://github.com/YunYouJun/advjs/issues/64)。

未来供应商提供可核验的正式音乐生成接口后，再实现独立的能力描述、预算审核、取消／恢复和结果登记。复用可信宿主与公共任务能力，但音乐任务不伪装为 `VoiceTake` 或 Qwen／OpenAI TTS 请求。未知收费结果不能自动重试；真实供应商调用与 COS 公开发布分别记录实际回执。

## 本地实施结果

上述六项流程任务已接入两端共享协议。生产 Editor 和 Studio 各通过 Chromium／WebKit 完整页面旅程，导入原创音频、实际试听后明确采用、保存 canonical JSON Flow，并通过普通项目构建播放准确 music 资产。未绑定候选与创作资料排除、音乐复审恢复、CAS／作用域和草稿保护均有独立回归；旧 BGM 保持兼容。来源、环境、截图与边界统一见[音乐流程验收](../reports/2026-10-11-audio-runtime-implementation#_2026-10-12-音乐创作与文件回流)，本地原始波形不作为实际 AI 音乐生成或真人评分证据。
