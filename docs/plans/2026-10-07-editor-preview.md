# Editor 预览与通用游戏操作栏

日期：2026-10-07。状态：内嵌、独立与实时预览已实现，macOS arm64 打包回归通过。验证见 [验收记录](../reports/editor-preview.md)。

## 范围与职责

- `AdvGameUI` 保留显示与设置工具；`DialogControls` 承载回看、自动、快进和存读档，复用三国工作区已经实现的组件、提示、显示偏好与回归用例。
- `AdvGame` 组合操作栏，保留当前头像、无头像排版和局部游戏主题；测量底栏高度给对白预留空间。游戏控件使用游戏 token，不套用 AGUI。
- 桌面预览宿主将同一沙箱游戏视图移入 Editor 或独立窗口，不重新加载剧情。原生层管理视图位置与资源回收；有限 preload 仅接收显示模式及面板矩形，不接受 URL 或脚本。
- `AEDesktopGamePreview` 只呈现 AGUI 运行方式、启动／重启、停止和显示位置；`useDesktopPreview` 共用菜单与面板操作，宿主状态决定活动会话。面板位置随调整更新，编辑器弹层出现时移开原生游戏视图，关闭后恢复。
- 实时预览默认使用 Vite，`live-worker` 监听作者已保存的文件并同步临时副本，`createProjectPreviewServer` 编译项目内容与资源、刷新玩家；构建预览继续调用 `advBuild` 验证静态输出。源文件写入仍由 `ProjectWorkspace` 负责，预览不自动保存草稿。
- `dialog-reading.scss` 共用玩家对白与阅读设置示例的字号和行高；`AdvDialogBox` 只负责人物与对白排版，按 `AdvContainer` 的逻辑画布尺寸响应，不读取作者宿主的窗口宽度。
- 默认首页统一标题与菜单布局、等宽按钮和共用玩家控件反馈；Editor 提供项目主题源码覆盖、跳转编辑与代码／需求复制入口，继续由 `ProjectWorkspace` 写入，不引入 AI 执行服务。

## 验收

1. 默认在「游戏」面板运行已保存项目；系统菜单与面板都能切换独立窗口，切换不重置当前剧情。关闭独立预览窗口返回面板。
2. 游戏没有桌面 preload、Node 或项目凭据；隐藏面板、打开弹层、停止、切换项目与退出不会留下覆盖、音频或临时服务。
3. 顶部不重复显示播放和存档工具；底栏有文字、状态、提示及常驻／自动收起／保持收起偏好，键盘操作不意外推进剧情。
4. 检查正常宽度与约 320px、长标签、亮暗主题、对白与旁白、存读档、自动／快进及选择流程。
5. 通过宿主与 Editor 构建、类型检查、相关单元和打包版流程；记录本次实际验证的平台及未验证范围。
6. 默认实时预览，保存正文、人物或资源后自动刷新，无需生产构建；未保存的草稿不影响玩家。独立窗口也自动更新，移动位置不重载；内容刷新重新开始当前游戏页面。
7. 内容错误通过全局通知提供复制信息，保留最后有效画面，修复保存后恢复。可执行配置变化停止服务并要求重新连接确认信任；停止、替换项目与退出回收监听、子进程、端口和临时目录。仍可切回构建预览与导出。
8. 常规画布默认正文 22px、姓名 20px、行高 1.5 倍；窄画布按共享规则收紧，保留玩家字号档位。在相同游戏尺寸下比较内嵌预览、独立窗口和普通浏览器中的生产构建，字号、留白、人物列与换行一致，正文不遮挡底栏。
9. 选项整组用 160ms 纯淡入、80ms 淡出，没有位移或逐项等待；进入时按钮立即可用。减少动态效果时使用 80ms，关闭动画或系统要求减少动态时直接出现，鼠标和键盘均可选择。预览与正式游戏复用同一组件规则。
10. 顶部图标、底部文字和快存／快读共用精简的按钮反馈与主题 token；悬停和键盘焦点可区分，开启状态有形状提示。操作提示在悬停或键盘聚焦时立即出现，保持在游戏内，采用紧凑的标题／说明层级；检查正常／320px、默认／自定义主题、Escape、键盘焦点和减少动态偏好，预览与正式游戏一致。
11. 默认首页检查正常／320px、标题菜单间距、等宽按钮、键盘焦点、减少动态及局部主题；「主题」能创建覆盖或打开已有文件，保护未保存草稿，复制真实相关代码与需求给外部 AI。保存源码后验证预览更新，生产构建使用同一覆盖与排版。
