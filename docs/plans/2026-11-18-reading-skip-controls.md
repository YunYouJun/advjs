## 共享接线

| 位置                                        | 接线要求                                                                                                                           |
| ------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `setup/context.ts`                          | 在同步 Pinia 当前节点之前更新已读状态。读档和回退成功时取消播放计时器。Extras 先设置内存存档模式，再用同一模式选择已读记录的存储。 |
| `composables/useAdvRuntime.ts`              | 两项功能共享 `onState` 的第四个参数 `effects`。Extras 用它过滤历史操作的解锁副作用，阅读控制用它识别恢复或回退。                   |
| `types/context.ts`、`runtime/index.ts`      | 合用各自的控制器类型和导出。                                                                                                       |
| `components/game/AdvGame.vue`               | 保留游戏快捷键根节点、退出清理和 Extras 成就提示。回想结束时，Extras 卸载玩家组件并聚焦返回按钮。                                  |
| `apps/studio/src/components/GamePlayer.vue` | 草稿使用内存已读记录，历史定位视图不接收游戏按键。保留 Extras 自己的草稿存储配置。                                                 |
| `docs/.vitepress/config/index.ts`           | 导航保留玩家操作与附录两个入口。                                                                                                   |
