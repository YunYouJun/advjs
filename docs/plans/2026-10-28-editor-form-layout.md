# 编辑器表单布局统一

状态：已完成（2026-10-28）。验证结果见 [检查报告](../reports/2026-10-28-editor-form-layout.md)。

范围：桌面 Editor（core、VRM）及 AGUI 共享控件。沿用 [AGUI 规范](../agui/design.md)，保留业务行为、键盘操作及亮暗主题。

## 实施与验收

- 统一 `AGUIProperty` / `AGUIFormItem` 的标签列、控件列及窄容器布局；由 `AGUIForm` 管理行间距，消除行外边距叠加。
- 抽取字段内边距、文字尺寸、表单行列间距 token；输入、选择、组合框及相关控件消费同一规则。
- 检查音频、角色、属性、偏好设置、创建与在线配置表单，迁移重复字段容器和手工标签布局。
- 在真实编辑器正常／窄面板、亮／暗主题中检查对齐、滚动、长标签、焦点及输入；共享组件回归、类型、构建与文档检查通过。
- 验证结果写入报告，清理本轮临时构建产物。
