# 背景音乐与主题曲创作

Editor 和 Studio 支持从音乐创作方案到文件导入、试听采用、章节／Flow 绑定和游戏播放。音乐由用户自创、委托创作或借助 AI 完成；两端使用同一份原生项目资料，播放复用 AudioEngine。

## 创作方案与外部工具

在音频素材库打开音乐创作方案，选择背景音乐、主题曲、OP、ED 或插曲，填写描述、情绪、风格和目标时长。节奏、器乐、循环意图与补充说明按需要填写。方案可复制为文本或下载为 JSON，交给自己的 DAW、创作者或 AI 工具。

Suno 入口打开[官方创作页面](https://suno.com/create)。可使用 [Custom 模式和自己的歌词](https://help.suno.com/en/articles/2415873)创作，再从[官方 Library／Workspace 下载入口](https://help.suno.com/en/articles/2409921)取得音频文件后导回项目。可下载的格式取决于其当前[产品能力与账号方案](https://help.suno.com/en/articles/13926081)，使用许可按[服务条款](https://suno.com/terms)和实际授权记录填写。

当前 Suno 集成是创作方案交接与文件回流。打开外部页面不会自动提交提示词或执行收费生成；来源网页地址只保存作者来源，不是播放器地址。方案中的目标时长和循环要求不代表文件的实际时长或无缝循环，需在导入后确认。

## 导入、试听与采用

1. 在素材库选择 BGM 并导入真实音频文件。可以导入自己创作的音乐，也可以导入已取得使用许可的 AI 输出或委托作品。
2. 填写音乐用途、创作方案、人工／外部 AI 来源、工具与来源页面，以及许可、署名和使用说明。资料保存在唯一 Asset Catalog；文件按稳定 asset ID、SHA-256 和字节数登记。
3. 使用素材的试听按钮检查声音与循环接缝，确认音乐适合章节和对白混音后显式采用。采用核验当前文件实际字节，并绑定其 SHA；拒绝保留素材，不删除原件。
4. 修改用途、创作方案、来源或许可后重新试听采用。修改标题等展示资料保留既有采用判断；冲突 revision 或损坏的母版需要先解决再操作。

采用表示作者确认当前素材可用于绑定，不是自动生成的音质评分。试听、导入和采用都不会自动替换剧情里的音乐。既有无新版音乐资料的 BGM 继续兼容；新资料和判断在 Editor、Studio 之间保持一致。

## 绑定章节与 Flow

从素材库进入章节绑定后，在现有编辑器确认目标章节和音频操作。Studio 快捷绑定在章节入口设置音乐；需要在剧情中途开始或更换音乐时，在已有 Flow 音频节点中编辑位置与操作。Editor 可在现有 Flow／脚本音频属性中绑定选定素材。JSON Flow 使用 canonical BGM 操作，Markdown 使用相同的 `advnode` 指令。主题曲、OP、ED 和插曲都是作者用途，运行时仍属于 `bgm` 并走 music 总线；不会因为选了主题曲就自动在开始界面播放。

下面是已有稳定资产 ID 的脚本示例。界面导入生成 `audio_<uuidv7>` ID，应使用实际条目 ID。

````md
```advnode
[
  {
    "type": "bgm",
    "action": "set",
    "asset": "bgm/summer-day",
    "gain": 0.7,
    "loop": true,
    "fade": { "in": 500, "out": 1000 }
  }
]
```
````

背景音乐默认建议循环，主题曲和 OP／ED 默认建议完整播放一次；这些参数可编辑，绑定前需按实际片段确认。场景结束可使用 `action: clear`；前进、回退、暂停／恢复、静音和对白 ducking 仍按[音频指南](./audio)的既有协议执行。

## 导出与发布

原生项目保留音乐资料与原件，便于跨端继续编辑。普通 JSON Flow 游戏构建收集剧情实际引用的新版音乐资源，排除未绑定候选和作者创作方案、来源说明与审核资料。播放器从 Catalog 解析真实文件或已验证的发布变体，不请求外部创作页面，也不加载 Suno 或 TTS SDK。

已有转码与 COS 发布继续使用[发布规范](./assets/cos)；音乐方案不授予云资源或发布权限。项目编辑和播放不需要常驻独立音乐服务，也不要求 CFS。未来正式自动音乐生成适配器的范围见[独立音乐计划](/plans/2026-10-12-ai-background-music-generation)。

## 验证

导入一份原创音乐，试听采用后在 Flow 音频节点绑定，保存并导出项目。启动普通游戏，确认音乐在所选节点开始，结束或清除节点停止；测试一次静音、暂停／恢复和对白期间音量变化。切换到另一端检查用途、许可和采用状态仍一致。

音乐许可或创作方案变更后，新绑定入口应要求重新采用；文件被改写时应报完整性错误。未绑定的新版音乐和方案不能出现在玩家包中。浏览器自动化与波形输出只验证操作和实际发声，音乐听感与第二台真实设备需分别验收；当前证据见[音频实现报告](/reports/2026-10-11-audio-runtime-implementation)。

已绑定音乐的资料回到 pending 时，编译显示 `ADV_AUDIO_MUSIC_REVIEW_REQUIRED`。原生资料仍可打开并重新试听采用；重新通过后再构建和播放。手写 Markdown 或 JSON Flow 同样检查该状态，不能绕过界面直接导出待审或拒绝的新版音乐。
