# 剧本编辑器

Editor 的「文件」面板使用 Monaco 编辑 `.adv.md` 剧本。可以从「故事 → 创建」添加世界观、场景与章节，再打开源码编辑；已有章节可以在光标处插入对白或选项模板。

## 创建世界观、场景与章节

1. 打开标准 Markdown 项目，选择「故事 → 创建 → 世界观／场景／章节」。
2. 输入名称。场景和章节还需要标识符，例如 `reading-room` 或 `chapter-02`；标识符用于文件名和剧情引用。
3. 检查对话框里的项目文件路径，点击「创建并编辑」。新文件立即保存到项目，并在「文件」面板打开源码。

创建使用 `adv.config.json` 声明的内容根目录。默认路径为 `adv/world.md`、`adv/scenes/<id>.md` 和 `adv/chapters/<id>.adv.md`。世界观已存在时，按钮改为「打开编辑」，保留原内容；重复场景或章节标识符会阻止提交。

有显式章节列表的 JSON 游戏配置会同步追加新章节，保留已有章节、入口和额外配置。自动发现章节的项目会在需要时固定原游戏入口与推断标识符，避免新文件改变已有故事。新场景包含名称与描述模板，后续按[资源目录](../assets/catalog)填写背景的 `assetId`。

当前文件有未保存修改或正在加载时，先保存或放弃修改再创建；取消对话框不会写入。写入失败保留表单，可以重试；文件已创建但打开失败时，重试只打开文件。可执行配置的虚拟 JSON 不能自动修改，需要先提供项目内的 JSON 游戏配置。没有打开项目、正在恢复或使用旧 JSON／Flow 格式时，创建命令不可用。

## 插入对白和选项

1. 在「项目」面板中打开一个 `.adv.md` 文件。
2. 在源码中放置光标，或选中需要替换的内容。
3. 点击文件面板上方的「插入对白」或「插入选项」。Web Editor 也可以使用「故事 → 创建 → 对话／选项」。
4. 修改选中的角色名或第一项选项文字，再补充对白和其他选项。

中文界面插入的模板如下：

```md
@角色
对白内容。

- [ ] 选项一
- [ ] 选项二
```

模板以空行与前后段落分隔，保留文件的换行格式。插入操作使用当前编辑器的撤销记录，不会覆盖已有草稿。处于阅读模式或其他主面板时，从菜单插入会返回当前剧本的源码。

没有打开可编辑的 `.adv.md` 文件、文件正在加载或源码编辑器尚未就绪时，插入命令不可用。模板不生成目标章节或跳转逻辑；需要跳转和动作时，按 [AdvScript 语法](../advscript/syntax) 修改选项。

## 查看项目分支图与定位源码

打开项目后，在主区域选择「流程图」。默认展示当前保存版本的章节概览，每章显示段落、剧情、选项和结局数量。点击章节的「展开」进入段落，再展开段落查看具体剧情。段落按一／二级标题、场景和文件边界聚合；三级及以下标题仍保留在段内。聚合只影响图的呈现，源文件、运行时剧情节点和跳转地址保持原有结构。

工具栏的章节选择进入该章的段落概览；「本章剧情详情」或「全部剧情详情」可以直接查看剧情节点。面包屑和「返回上一层」返回上级视图，并恢复已查看视图的方向、位置与缩放。超长章节或段落按每页 200 个节点分批展示，另保留最多 40 个指向其他区块的门户；「上一页」「下一页」继续查看。跨章、跨段和跨页跳转仍能展开至准确目标。

点击聚合连线可打开「跳转明细」，查看每条实际跳转的条件、来源和目标源码位置，或直接展开目标。大量边界目标合并显示时，点击「查看跳转」逐条选择；明细每页显示 50 条。高密视图最多绘制 600 条连接，超出的关系收进「其他连接」汇总节点，全部实际跳转仍可在明细中查看和展开。汇总节点旁的虚线仅表示连接集合。

首次进入视图会按当前节点实际尺寸自动排版并取景，超长直线和复杂连线使用紧凑网格，避免全页取景把操作按钮压缩成细线。工具栏可以切换水平／垂直布局，选中方向会高亮；点击「自动排版」按当前方向重新整理。缩放后点击「显示全部节点」只恢复当前页的取景。缓存复用未变章节的源码位置索引、视图和布局；刷新后仍会重新计算剧情关系、诊断与静态可达性，项目编译仍处理完整剧情。

节点类型配有不同图标和文字：章节、段落、对白、旁白、选项、分支、跳转、场景、动作、演出、锚点与结局可直接区分；未知插件类型使用拼图图标。

可以通过欢迎页创建「你好，ADV.JS」示例，体验章节概览、逐层展开、三章分支、回看循环、条件选项与两种结局。

点击节点文字或用键盘激活节点按钮，会切换到「文件」源码视图，定位对应文件的行列并聚焦编辑器。展开图下方的「项目诊断」，点击文件位置也可以定位错误或警告。编译失败时，图保留可确认的章节与诊断，修复并保存后恢复剧情关系。

「静态可达」表示从游戏配置入口出发的可能路径，不是玩家试玩覆盖率。条件分支保留条件提示；宿主或插件的动态导航可能使其他节点的可达性未知。图为只读，修改剧情仍在源码中进行。

定位使用保存版本的行号。当前源码或角色表单有未保存修改时，先保存或放弃草稿再定位；外部修改导致源码与图不同步时，点击「刷新」后重试。保存后图会更新，切换项目会移除旧项目的图与定位请求。

## 保存与验证

插入后，文件名旁显示未保存标记。使用 `⌘Z`（Windows／Linux 为 `Ctrl+Z`）可以撤销整个插入块，已有草稿仍保留。只有点击「保存」才会写入项目文件；「放弃修改」恢复最近保存的版本。

保存后检查游戏预览中的对白或选项；遇到编译错误时，按诊断定位剧本内容。更多运行时操作见 [运行时导航与存档](../runtime/navigation-and-saves)。
