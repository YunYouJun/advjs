# 基础操作

> <https://editor.advjs.org>

## 切换语言 {#switch-language}

ADV.JS 编辑器支持中文（简体）和 English，菜单、主要工作区面板、人物卡与创作上下文可以即时切换。

### 默认跟随浏览器

没有手动语言偏好时，编辑器按浏览器语言列表的优先级选择支持的语言。`zh`、`zh-CN`、`zh-TW`、`zh-HK` 等中文变体使用简体中文，`en` 及其地区变体使用英文；未找到支持的语言时回退到英文。

自动识别不会把推断结果保存成手动偏好。选择「跟随浏览器」后，再次打开或浏览器触发语言变化事件时会重新识别。已有的有效手动偏好继续优先，不因浏览器语言改变而被覆盖。

### 随时切换

工具栏右侧的语言下拉框提供三个选项：

- **跟随浏览器 / Follow browser**：自动识别。
- **中文（简体）**：固定使用简体中文。
- **English**：固定使用英文。

也可以在 `编辑 → 偏好设置 → 界面`（`Edit → Preferences → Interface`）切换。人物管理独立页面使用同一个语言控件。手动选择会保存到当前站点的浏览器本地存储，刷新或重新打开后恢复。

首次引导可以手动选择语言，也可以跳过并保留自动识别结果。语言选择只影响编辑器界面，不改写人物卡、剧本、游戏文本或文件路径。
