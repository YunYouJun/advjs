# 功能与设计特点

ADV.JS 是面向 Web 的可编程文字冒险游戏引擎：用 Markdown 编排叙事，用 JavaScript / TypeScript 组装运行时、界面与业务能力。它既可以制作完整的文字冒险游戏，也可以作为剧情模块嵌入已有 Web 游戏。

## 模块化编程与按需组装

模块化是 ADV.JS 的设计特点。编译器、剧情运行时、客户端、主题与宿主活动具有明确边界，开发者可以按项目需求组合它们；完整游戏和轻量嵌入共用同一套 Program 与运行语义。

| 能力       | 组装方式                          | 项目如何选择                                   |
| ---------- | --------------------------------- | ---------------------------------------------- |
| 剧本编译   | `@advjs/core/compiler`            | 在构建阶段把 `.adv.md` 编译为 JSON Program     |
| 剧情执行   | `@advjs/core/runtime`             | 执行对白、选择、条件、章节跳转与快照           |
| 游戏界面   | `@advjs/client`、主题或宿主 UI    | 使用 ADV.JS 客户端，或沿用游戏已有界面         |
| 业务与互动 | 运行时插件与宿主活动              | 连接任务、小游戏或 AI 服务，由宿主执行真实业务 |
| 创作工具   | CLI、Editor、Studio 与 Agent 工具 | 按创作流程选用，不要求玩家端加载创作工具       |

剧本负责“说什么、选什么、进入哪个分支”，JavaScript / TypeScript 负责宿主交互、业务规则和扩展实现。活动协议把两者连接起来：剧情提出请求，宿主处理并返回结果，运行时继续编排。宿主仍掌握背包、奖励、任务与其他游戏状态。

## 按需导入与加载

轻量运行时提供独立的 ESM 子入口。消费端可使用命名导入进行 tree shaking，并用动态 `import()` 在交谈开始时加载运行时与所选剧本；Markdown 编译器留在构建阶段。

同一故事的多份 `.adv.md` 可以编译为多章节 Program，共享变量与快照。需要按 NPC 或地区分别下载时，则编译为独立 Program，由宿主加载目录选择会话，并为每次交谈创建独立 Runtime。

这里的按需组装有明确边界：命名导入不保证状态机内部每个功能都能独立裁剪；单个 Program 的章节随 JSON 一起加载。实际产物与加载行为由消费端打包配置决定。SDK 包装、分块、编译与会话示例见[轻量运行时与 Web 游戏嵌入](./runtime/embedding)。

## 嵌入已有 Web 游戏

已有游戏可以保留自己的场景、渲染、输入、存档和 UI，把 ADV.JS 用于 NPC 对白、任务交流或分支剧情。轻量运行时不依赖 Vue、默认主题或场景加载器；宿主负责显示剧情数据、管理输入与焦点，以及同步游戏状态。

例如，大云游戏的 Vue / Three.js 场景使用预编译剧本和宿主活动完成陈叔对白、骑手登记与配送接单，在首次交谈时加载剧情模块。实际验证与发行边界见[嵌入验证报告](/reports/2026-10-08-headless-game-integration)。Agent 辅助集成和实时 NPC 对话见 [Web 游戏 AI 接入](/ai/web-game-integration)。

轻量子入口已在当前工作区实现；正式接入应检查目标发行物的 `exports` 并固定已验证版本。完整接入步骤与包版本说明以[嵌入指南](./runtime/embedding)为准。

## 富文本

完整客户端支持富文本对白；轻量嵌入时由宿主的文本组件决定渲染方式。

譬如：

```html
<font color="red" size="40">你好</font>**鸭** 早上**好**
```

<font color="red" size="40">你好</font><strong>鸭</strong>
早上<strong>好</strong>

完整客户端还可以结合 HTML、CSS 与 UnoCSS 工具类控制文本样式。

譬如：

```html
<span text="red" bg="black" p="2">红色</span>
```

<span text="red" bg="black" p="2">红色</span>
