## Local

执行以下命令，以在本地创建一个 advjs 项目模版。

```bash
pnpm create adv@latest your-adv
```

With NPM:

```bash
npm init adv
```

With Yarn:

```bash
yarn create adv
```

进入目录并启动：

```bash
cd your-adv
pnpm i
pnpm run dev
```

## 从仓库 Demo 开始

如果正在参与 ADV.JS 本身的开发，可以直接运行仓库内的两个完整项目：

```bash
pnpm demo           # 最小入门项目，默认端口 3333
pnpm demo:hamster   # 完整仓鼠旗舰示例
```

想复制一份最短项目时从 `demo/starter` 开始；想了解多章节、条件分支、插件活动、Studio 元数据与本地素材组织时查看 `demo/hamster`。更多边界说明见 [Demo 与 Examples](./demos)。
