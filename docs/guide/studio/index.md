# ADV.JS Studio

ADV.JS Studio 是一个移动端/Web 端的 ADV.JS 项目管理与创作工具。

## 概述

Studio 旨在让创作者能够随时随地管理和预览自己的视觉小说项目，无需依赖桌面 IDE。它提供了直观的文件管理、AI 辅助创作和实时预览功能。

**访问地址**: [studio.advjs.org](https://studio.advjs.org)

## 功能介绍

### Workspace（工作区）

工作区是 Studio 的核心功能页面，合并了项目管理和文件浏览。

**无项目时 — 欢迎页**：

- 快速操作卡片：创建新项目、打开本地项目、从 URL 加载、从云端加载
- 最近项目的精选大卡片展示
- 历史项目列表（支持左滑删除）

**有项目时 — 工作区视图**：

- **文件树浏览**：基于 AGUI AssetsExplorer 组件，支持展开/折叠、面包屑导航、右键菜单
- **文件预览**：双击文件在 Monaco Editor 中查看，支持语法高亮
- **Diff 对比**：AI 修改文件后可查看修改前后对比
- **项目切换**：右上角下拉菜单快速切换项目
- **内容编辑器**：表单化创建/编辑角色、章节、场景、地点，支持 AI 辅助生成

### 托管 AI 创作

Studio 使用云乐坊账号和 AI 点数提供五项托管能力：剧情大纲、章节草稿、情节建议、角色扮演模拟和一致性检查。模型、提示词、价格和安全规则由服务端管理，生产版不要求用户填写 API Key。

生成的大纲和章节草稿会先进入提案审阅，只有用户确认后才写入项目。任务进度、预占点数和实际结算显示在全局任务轨中。完整边界见 [Studio 托管 AI 与 Editor 本地 Agent](./ai-service)。

### World（世界）

项目世界设定与角色状态的浏览入口：

- **角色列表**：展示项目中的所有角色卡片，显示头像/初始字母、心情、位置、标签
- **动态状态**：角色位置、健康、活动、自定义属性实时变化
- **世界时钟**：浏览项目日期、时段和天气状态
- **世界事件**：浏览已有的事件记录
- **视角模式**：角色模式（扮演已有角色）、上帝模式（全知视角）、访客模式（旁观者）
- **专业角色**：通过 `knowledgeDomain` + `expertisePrompt` 字段支持领域专家角色
- **知识库系统**：从 `adv/knowledge/` 加载 `.md` 知识文件，供本地检索和外部 Agent 使用
- **角色关系图谱**：SVG 可视化展示角色间关系网络
- **世界时间线**：时间轴视图聚合世界事件与角色日记，支持类型/角色过滤
- **情感弧光**：角色好感度/信任度趋势折线图

通用聊天、角色聊天、群聊、角色日记生成和自动世界事件在完成托管能力登记前不出现在生产版，也不会回退到浏览器直连模型。

### Play（播放）

预览当前项目的内容：

- 查看 `world.md` 世界观概要
- 浏览章节列表和内容
- 统计信息（章节数、角色数）
- 云端同步操作（推送、拉取、手动同步）

### 资源管理

#### 地点管理

在 Workspace → 地点页面管理项目中的地点定义：

- **浏览列表**：显示 `adv/locations/` 目录下的所有地点文件
- **创建/编辑**：表单化创建地点（ID、名称、类型、描述、标签）
- **关联资源**：将地点关联到场景和角色
- **地点关系图**：纯 SVG 可视化展示地点间的共享角色关系

地点以 `.md` frontmatter 格式存储在 `adv/locations/` 目录：

```yaml
---
id: shibuya-cafe
name: 涩谷咖啡厅
type: indoor
tags:
  - 主线
  - 日常
linkedScenes:
  - cafe-morning
linkedCharacters:
  - jane
---
位于涩谷中心的温馨咖啡厅，是简的常去之地。
```

::: tip 场景 vs 地点
**场景**（`adv/scenes/`）是叙事中的视觉单元，包含背景图和 AI 图片生成提示词。
**地点**（`adv/locations/`）是世界观中的地理实体，用于追踪角色位置。
一个地点可以对应多个场景（同一咖啡厅的"早晨"和"夜晚"是两个不同场景）。
:::

#### 场景图片

场景卡片支持本地图片和远程 URL 缩略图。在场景 frontmatter 中可保存 `src` 和 `imagePrompt` 字段；Studio 当前只保存/复制提示词，不直接调用图片模型。

#### 音频资源

在 Workspace → 音频页面管理项目的音频文件（浏览、内联播放、导入、元数据编辑、关联场景/章节）。

### Me（我的）

个人中心与设置入口，采用 iOS Settings 风格布局：

- **设置** — 托管 AI 服务与点数、外观、云同步、清除缓存
- **反馈** — 前往 GitHub Issues
- **关于** — 版本信息与文档链接
- **开发者选项** — 连续点击 Logo 5 次开启（类似 Android 开发者模式）

## 使用说明

### 创建项目

1. 打开 Studio，在工作区欢迎页点击「创建新项目」
2. 输入项目名称，选择模板（5 种内置模板）
3. 选择本地文件夹作为项目目录
4. 项目自动创建并打开

### 打开已有项目

1. 点击「打开本地项目」
2. 选择包含 ADV.JS 项目的文件夹
3. Studio 自动检测项目结构

### 从素材生成项目

旧版浏览器直连模型的 Source-to-Project 入口已在生产版关闭。完成服务端 capability、价格、安全校验和提案审阅登记前，Studio 不会使用旧 API Key 配置继续生成。

当前可以在本地 Editor 中配合 Codex/Skills/MCP 整理长素材，或先创建模板项目，再使用 Studio 已开放的五项托管能力逐步创作。

### 托管资源存储

1. 本地打开项目并导入或生成媒体；Studio 会写入 `adv/assets/` 并登记稳定 `assetId`。
2. 登录 Studio 账号。
3. 在场景或音频资源卡点击发布按钮；浏览器只获得当前对象的短期 PUT 地址。
4. 服务端校验大小、MIME 和 SHA-256 后写入私有资源目录；可在「我的」→「设置」→「资源存储」检测服务状态。

Studio 不再要求用户填写 COS SecretId/SecretKey，旧版本保存过的长期密钥会在升级后从本地设置中移除。项目源文件默认保持本地；团队源文件同步与二进制资源发布是两个独立能力。

### 专业角色与知识库

角色可通过 `.character.md` 配置专业领域：

```md
## 知识领域

法律

## 专业提示

你是一名资深律师，精通刑法和民法……
```

在 `adv/knowledge/` 目录下放置领域知识文件：

```text
adv/knowledge/
  law/
    criminal-law.md
    civil-law.md
  general/
    overview.md
```

系统可以按 `##` 标题拆分为 section 做本地关键词检索。Studio 当前不会调用远程 Embedding 服务；需要向量检索或专业问答时可在本地 Editor 的 Agent 工作流中处理。
