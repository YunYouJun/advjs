## 紧凑资源工作区

目录树、面包屑、资源列表和底部缩略图尺寸控制共用 AGUI token。列表行最小 24px，名称维持 12px，不随缩略图缩小到不可读字号；长名称截断后可通过悬停查看完整标题。

工具栏筛选框匹配当前目录的文件／目录名称，不递归搜索。改变目录会清空筛选，改变筛选会清空选择；全选与范围选择只作用于当前可见项。无结果时显示空状态。

- 单击选择；Ctrl / Cmd 单击切换多选；Shift 单击选中连续范围。
- 方向键在列表或缩略图网格内移动并选择；Ctrl / Cmd + 方向键只移动焦点，Shift + 方向键扩展范围。
- Space 切换当前项选择；Enter 打开当前项；F2 重命名；Escape 取消重命名并返回当前项焦点。
- 原有复制、剪切、粘贴、复制副本、删除与全选快捷键继续有效，编辑输入时不会触发这些命令。
- 打开工具栏或菜单不会自动清空选择；点击列表空白处或按 Escape 清空选择。

缩略图区沿用共享滚动条，底栏可换行。拖动分割条时，资源内容随面板伸缩，默认不使用局部固定深灰色或自定义滚动条覆盖主题。
