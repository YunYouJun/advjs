# 桌面编辑器设计规范

本页属于 [ADV.JS 统一设计体系](/about/design/design-system)中的创作工具 UI。内嵌游戏内容遵循 [游戏 UI 规范](/about/design/game-ui)，游戏主题配置不得覆盖 AGUI 控件。

AGUI 是 ADV.JS 编辑器的 GUI 组件库。桌面编辑器采用**中性灰、紧凑控件、可调整面板、克制强调色**的专业创作工具风格，让剧本、角色、场景与预览成为视觉中心。

## 适用范围与规范入口

本页是 `editor/core/`、`editor/vrm/` 的编辑器外壳与 `packages/gui/` 组件的视觉规范。创作上下文、AI、资源、属性等新面板都必须遵守，不因功能不同重新设计一套颜色和控件。

- `AGENTS.md`：要求开发者和 agent 阅读本页，列出必须遵守的边界。
- 本页：定义视觉层级、组件使用方式、尺寸和验收标准。
- `packages/gui/client/styles/css-vars.scss` 与共享组件：承载可复用的实现值和交互状态。

本规范优先于全平台设计文档中关于品牌色、渐变、卡片尺寸的通用描述。`apps/studio/` 保留移动优先规范；游戏画面、封面、角色图与主题不受编辑器外壳配色限制。`.superdesign/` 等生成的设计稿上下文不作为规范来源。

### 参考方式

以 [Blender 的区域与面板组织](https://docs.blender.org/manual/en/latest/interface/window_system/index.html)为主参考，借鉴其主编辑区、局部工具栏与可折叠面板；以 [Godot Inspector](https://docs.godotengine.org/en/stable/tutorials/editor/inspector_dock.html)补充属性分组、搜索与随选择更新内容的交互参考。

参考这些工具的组织方式，不逐像素复制皮肤。ADV.JS 的长篇中文剧本需要独立的阅读字号与行高；桌面控件也要保留清晰标签、键盘焦点和合理的点击区域。

## 设计原则

### 编辑器优先

AGUI 不是通用 UI 库，而是为**编辑器场景**量身定制的组件体系。与常见的网页 UI 库不同，AGUI 的设计目标是：

- **紧凑**：小字号（12-13px）、低行高、小圆角（2-3px），减少视觉噪音，让用户聚焦于内容
- **高密度**：控件视觉高度以 20–24px 为基线，通过对齐和分组提高密度，不依赖缩小文字
- **克制**：装饰极少，无多余阴影和动效，信息传达优先

### 主题策略

编辑器默认使用暗色模式，同时提供完整的亮色模式以适配环境与个人偏好。两种模式共用尺寸、布局、组件语义和交互状态，分别调整表面、边框与文字对比度；亮色模式也需要完成键盘焦点、浮层与窄面板验收。[Blender 同样提供 Blender Light 主题预设](https://docs.blender.org/manual/zh-hans/4.5/editors/preferences/themes.html)，参考其紧凑工作区不意味着只支持暗色。

桌面编辑器通过 **编辑 → 偏好设置 → 主题 → 主题预设** 选择「跟随系统 / 亮色 / 暗色」。跟随系统时实时响应系统外观变化，手动选择亮色或暗色后保持固定；当前选择由 Nuxt Color Mode 持久化，刷新页面继续生效。原应用菜单的偏好设置入口继续可用，语言设置位于「界面」。宿主将主题作用于 `html`，让 Portal 渲染的弹窗、菜单和下拉列表同步继承。业务面板不自行添加 `.dark` 或固定颜色。

### 无障碍与可访问性

底层采用 [Reka UI](https://reka-ui.com/) 作为无头（headless）组件基础，复用其 ARIA 语义和键盘导航。封装后仍需验证可访问名称、焦点、禁用状态和操作顺序；使用无头组件不等于已经完成无障碍验收。

## 技术架构

### Reka UI + AGUI 样式层

AGUI 的组件分为两类：

| 类型             | 说明                                  | 示例                                                           |
| ---------------- | ------------------------------------- | -------------------------------------------------------------- |
| **Reka UI 封装** | 基于 Reka UI 无头组件，叠加 AGUI 样式 | Dialog、DropdownMenu、Switch、Tabs、Slider、Accordion、Menubar |
| **自建组件**     | 直接基于 Vue 构建的编辑器特有组件     | Button、Input、ColorPicker、Tree、Explorer                     |

这种分层架构的职责是：

- Reka UI 提供交互语义和键盘行为的基础，AGUI 负责封装后的验证
- 视觉风格由 AGUI 统一控制
- 编辑器特有的组件（如 Properties Panel、Assets Explorer）可自由定制

### 关于 TDesign

TDesign 已被完全移除。编辑器中原先使用的 TDesign 组件已全部替换为基于 Reka UI 封装的 AGUI 组件，统一了视觉风格并减少了外部依赖。

## 色彩体系

AGUI 通过 CSS 自定义属性（`--agui-c-*`）定义色彩。下表列出现有 token，实际值以 `packages/gui/client/styles/css-vars.scss` 为准，业务组件引用变量而非复制色值。缺失的语义 token 应在共享层补充。

### 使用规则

- 外壳、面板、内容背景使用中性灰阶；以表面差异、1px 分隔线和留白分组。
- 蓝色用于焦点、选中和必要的主操作。一个局部任务组最多一个主按钮，也可以全部使用普通按钮。
- 绿色只表达成功状态，黄色表达警告或待处理状态，红色表达错误或破坏性操作。状态同时提供文字或图标，不能只靠颜色。
- 刷新、复制、打开、AI 相关操作默认使用中性按钮；“AI”本身不是一种颜色语义。
- 禁止在编辑器外壳中新增装饰渐变、发光、大面积饱和色或给每个统计数字分配不同颜色。品牌标识与真实素材缩略图可以保留原色。
- 不在业务面板使用 `bg-blue-600`、`bg-green-600`、`dark:bg-gray-800` 等固定调色板类另造主题；UnoCSS 继续用于布局。

### 共享控件 token

按钮统一使用 `--agui-control-height: 24px`；有底色的普通按钮使用 `--agui-c-control` / `control-hover` / `control-pressed`，透明图标按钮使用独立的 `--agui-c-icon-hover` / `icon-pressed`。图标悬停采用轻量叠加色（亮色为 6% 黑色、暗色为 10% 白色），随所在表面适配；按下态分别为 12% 黑色、6% 白色，比悬停态略深。普通文字按钮的边框使用较轻的 `--agui-c-button-border`，字段、复选框等需要轮廓识别的控件使用 `--agui-c-control-border`。主操作和危险操作分别使用 `--agui-c-primary*`、`--agui-c-danger*`，文字使用 `--agui-c-on-accent`、`--agui-c-danger-text` 与 `--agui-c-link`。它们在共享 token 文件中提供亮暗两套值。折叠分组使用 `--agui-c-bg-summary`，业务面板不自行覆盖这些颜色。

字段底色使用 `--agui-c-field`；成功、待处理文字使用 `--agui-c-success-text` / `--agui-c-warning-text`；危险提示底色使用 `--agui-c-danger-soft`，搭配 `--agui-c-danger-text`；模态遮罩使用 `--agui-c-overlay`。不要将状态色用作普通操作的背景。亮色 `text-2` 使用实色 `#595959`，在白色面板与 `#f2f2f2` 标题背景上的对比度分别约 7.00:1 与 6.26:1，在按下态 `#d4d4d4` 上仍约 4.73:1；暗色面板上的 `text-2` 约 4.67:1。其他背景或叠加透明度需重新检查。

菜单、下拉框与组合框统一使用 `--agui-c-popup`、`--agui-c-border` 和 `--agui-shadow-popup`，弹窗也复用边框与阴影。面板边界和普通分隔线共用 `border` / `divider`（亮色 `#c7c7c7`、暗色 `#545454`），弱分隔线使用 `divider-light`（亮色 `#e2e2e2`、暗色 `#484848`）；暗色也使用实色，避免同一条线在不同表面上显出不同颜色。浮层阴影与模态遮罩分开定义，避免亮色菜单出现过重的黑色阴影。通知使用中性浮层和正文色，通过状态边线与图标表达信息、成功、警告或错误；普通通知不使用白色文字覆盖亮色背景。滚动条使用 `--agui-c-scrollbar` / `--agui-c-scrollbar-hover`，分割条的常态颜色是 `divider` 的别名，拖动区域与悬停提示继续使用共享尺寸和颜色 token。

共享文件按「基础调色板 → 亮色语义默认值 → 暗色覆盖 → 主题别名」组织。`--agui-c-label`、`--agui-c-text`、`--agui-c-bg-summary` 与品牌兼容别名在 `:root` 和 `.dark` 边界重新解析；`--agui-c-bg-1/2` 在亮暗两种模式均有默认值。业务组件消费语义 token，不直接引用 `text-light-*` / `divider-dark-*` 等调色板值，以免切换主题后仍保留旧色。

## 组件风格规范

### 尺寸基线

以下是新增与迁移 UI 的目标值，不代表所有现有组件已经达标。

| 项目                 | 基线                                                |
| -------------------- | --------------------------------------------------- |
| 控件、树行、属性标签 | 12–13px，常规字重；分组标题可用 600                 |
| 辅助元信息           | 11–12px；不得用 9px mini 字号承载主要操作或必要信息 |
| 剧本、世界观等长文   | 13–14px，行高 1.5–1.7，正文默认无衬线字体           |
| 控件视觉高度         | 20–24px；点击区域至少 24×24px，图标可小于点击区域   |
| 工具栏、面板标题     | 24–28px；允许长标签换行或进入溢出菜单               |
| 间距                 | 4 / 8 / 12 / 16px；2px 仅用于图标微调和相邻控件细缝 |
| 面板内边距           | 8–12px；同级分组保持一致                            |
| 圆角                 | 控件 2–3px，弹层 4–6px；停靠面板保持直角            |
| 图标                 | 常规 14–16px，颜色继承文字                          |

字体优先继承编辑器的系统无衬线字体栈，等宽字体用于源码、路径和日志。不要把所有创作资料强制显示成代码块。正文需达到 4.5:1 对比度；低对比 token 不用于必要说明和表单标签，按实际背景组合检查。

### Button

文字及图标加文字的操作使用 `AGUIButton`，纯图标工具使用 `AGUIIconButton`，不在面板重新绘制按钮：

| 场景                       | 组件选择                                     |
| -------------------------- | -------------------------------------------- |
| 刷新、复制、打开等常规操作 | 默认 `theme="default"`                       |
| 当前任务的主要提交操作     | `theme="primary"`                            |
| 删除等破坏性操作           | `theme="danger"`，按影响范围提供确认或撤销   |
| 次要或低频动作             | `variant="outline"` 或 `variant="text"`      |
| 异步操作                   | `loading` / `disabled`，完成后用局部状态反馈 |
| 全屏、刷新等纯图标工具     | `AGUIIconButton`，常态无可见边框             |

- 支持 `data-location` 属性实现按钮组拼接（LEFT / RIGHT / ALONE）
- 不用 `flex-1` 将一对常规操作拉成整行彩色大按钮；操作放在面板或分组工具栏内。
- 只有图标的按钮必须有可访问名称和可见的操作说明入口（如 tooltip）。
- 图标和文字的间距由按钮容器的 `gap` 提供；不在图标上固定单侧外边距，以免纯图标或仅加载指示器时偏离中心。纯图标按钮为 24×24px，图标水平和垂直居中；常态背景透明，悬停和按下分别使用 `icon-hover` / `icon-pressed`，禁用按钮不响应悬停。切换操作通过 `active` / `aria-pressed` 表达状态，激活态继续使用主操作颜色；键盘焦点环放在点击区域内侧，避免被相邻面板裁切。
- 标签栏统一使用 `--agui-tab-list-height: 28px`，有无操作按钮的相邻面板保持同高。操作区上下留白 2px、左右留白 4px，相邻操作间隔 2px；保留 24px 点击区，使悬停背景与栏边缘、分割线分开。尺寸由共享组件控制，不在调用方另加外边距。

### Input

复用 `AGUIInput`、`AGUIInputNumber` 等控件。属性采用标签与字段对齐的行布局，窄面板可改为上下排列。标签始终可见，不用 placeholder 替代；错误提示靠近字段，焦点态使用 `--agui-c-focus`。

`AGUIInput`、`AGUIInnerInput` 与 `AGUITextarea` 共享 `input/fields.scss`。单行输入与 `AGUISelect` 高度为 24px；属性表给下拉框传递 `label`，输入框将 `id`、ARIA 和 `disabled` 传到实际字段。开关的可见标签须关联唯一 ID，调用方可传入 `id`。

下拉框的选中文本随选项标签更新，切换语言不改变选中的值；长文本在触发器内省略，完整值可通过提示或展开菜单查看。

`AGUICombobox` 的建议列表以输入字段为定位锚点，宽度跟随字段，使用共享浮层 token。输入、清空和选中建议均更新同一个 `modelValue`；选择一次后仍可重新搜索其他建议。无匹配时显示可读的空状态，自由输入的地址不要求存在于建议列表。

### 弹层（Dropdown / Context Menu）

复用 AGUI 菜单组件，以中性表面、边框和轻量阴影区分浮层。默认采用足够不透明的背景，避免复杂游戏画面透过弹层影响阅读；不新增装饰性毛玻璃效果。

- 菜单项高度 25px，字号 12px
- 高亮态使用 `--agui-c-active`（蓝色系）
- `AGUIDropdownMenu` 的 `trigger` 插槽允许用共享图标按钮触发菜单，保留可访问名称、当前状态和完整提示；默认文字触发器继续可用。

`AGUIDialog` 统一使用 28px 标题栏和中性关闭按钮，正文区独立滚动，宽高不超出当前视口。菜单样式只重置自身控件，不允许全局 `button { all: unset }`。

### 动画与焦点

- hover、展开与状态过渡控制在 100–200ms，尊重 `prefers-reduced-motion`。
- 不使用卡片悬浮位移、弹跳或循环装饰动画。
- 保留清晰的 `:focus-visible` 指示，禁止无替代地使用 `outline: none`。
- 分割面板拖动时不对尺寸应用动画，避免指针与布局脱节。

## 布局

macOS 桌面宿主的打开／最近项目、重新连接、预览、导出、扩展管理与布局命令由系统菜单承载，窗口顶部不重复铺开全局命令按钮。项目文件夹名进入原生标题栏，未保存状态同时用标记表达。窗口底部保留紧凑状态栏，显示连接、保存、文件／光标位置与构建状态；任务详情承载取消、日志、显示结果和复制报告。运行错误进入右下角全局通知，位于状态栏上方，提供「复制信息给 AI」与日志入口，不能撑高顶部工作区。通知最多同时显示三条，通知区域不超过窗口一半高度；关闭或被新通知替换后仍可查阅日志。扩展操作从「视图 → 编辑器扩展」打开的插件面板进入。项目切换器同时列出已打开与最近使用的项目；已打开项直接聚焦对应窗口。Web 与其他宿主继续使用各自的窗口内菜单和工具栏。

默认工作区按创作职责分工：左侧「项目 / 故事线 / 人物」分别承载文件导航、叙事结构和人物入口；中间承载文件编辑、阅读、游戏预览及流程图；右侧检查器展示当前选择的属性；底部「素材」浏览图片、音频、视频与模型，并与控制台、诊断等辅助面板共享标签区域。

桌面「游戏」区域使用紧凑 AGUI 工具栏分别提供运行方式（实时／构建）、启动／重启、停止和预览位置，默认实时与内嵌，允许切换独立窗口。实时预览在保存后更新；状态栏显示运行、更新或失败，详细日志和复制信息仍位于全局通知与任务详情。游戏视图与工具栏保持权限和视觉边界；切换位置不重新加载剧情。原生视图随面板矩形更新，在面板隐藏或编辑器弹层显示时移出覆盖区域，不能挡住设置、菜单、通知或状态栏。

桌面空窗口显示独立中央欢迎页，集中呈现打开项目、示例与基础模板、最近项目；暂时收起停靠面板，打开项目后恢复该项目的工作区。欢迎页不写入或覆盖已保存的面板比例。最近列表支持按名称和路径搜索，已打开项目用文字标明，点击后聚焦对应窗口。示例包含可运行的剧本和本地素材，桌面创建表单分别提供游戏显示名、文件夹名与存储位置，确认前展示完整路径；原生目录选择器用于更换父目录，创建时拒绝覆盖已存在目录。中央欢迎页可使用 24px 标题；模板配图属于作品素材，编辑器背景和控件仍使用 AGUI token，一个模板组最多一个主操作。

Web 的创建、打开、最近项目与恢复授权入口继续位于「项目」面板。显式进入空编辑工作区后，「项目」提供返回欢迎页的紧凑入口，「游戏」仅显示预览空状态和「前往项目」入口；项目就绪后显示预览操作或游戏画面。独立加载的配置仍可在 Web Editor 中预览。

文件树单击或键盘 Enter 打开文件到主区域，人物文件同时联动人物检查器。Markdown 提供源码与阅读视图，图片和音视频采用对应媒体预览；不支持的格式展示文件信息。未保存修改需要先保存或明确放弃，切换视图不会丢失当前文件。底部素材采用缩略图或列表，不承载长篇剧本编辑。用户调整后的面板比例继续保留，旧底部「项目」标签迁移到左侧「项目」与底部「素材」。

素材浏览器内部保留目录侧栏，默认约 200px，可折叠并通过拖动或键盘调宽。目录树仅包含有素材的目录及其祖先，右侧按目录、类型和搜索条件展示素材。工具栏保持一行：进入子目录后在栏内显示面包屑，根目录不重复显示「全部素材」路径行；搜索框旁的范围菜单区分「当前目录及子目录」和「全部素材」，提示显示当前范围。素材数量为行内元信息，完整文件路径通过素材提示与检查器查看，不另占固定状态栏。

宽度不足 640px 时，路径改为可返回祖先的目录菜单，视图切换与项目定位进入操作菜单。宽度不足 520px 时默认收起侧栏，仍可手动展开。可用内容高度不足 120px 时减小缩略图，不足 80px 时采用小图与名称并排的紧凑项，优先保证至少一行素材可读；不覆盖用户保存的面板比例。

素材单击或方向键选中并更新检查器，双击或 Enter 打开主区域预览；浏览、筛选和定位不替换当前文件或未保存内容。项目树与素材浏览器共享文件数据，提供双向定位，分别保留浏览位置。目录、侧栏开关与宽度、列表模式和浏览范围可恢复；查询与临时选中项不跨刷新恢复。目录删除后回退到仍存在的祖先。

控制台工具栏保持单行，清空、类型筛选、搜索与复制共用紧凑布局；日志区独立滚动，低高度面板中不能覆盖工具栏。复制采用带名称和悬停提示的图标按钮，工具栏与日志行的复制操作对齐，并为非覆盖式滚动条保留相同空间。对勾仅表示复制成功，提示区分当前日志与单条错误，两秒后恢复复制图标；成功状态不改变按钮宽度。错误摘要与详情允许换行，单条日志的复制操作保持在右上方；剪贴板不可用时通过弹窗提供可手动复制的报告，不能将报告插入工具栏撑高面板。

控制台的合法 JSON 数据默认高亮键名、字符串、数字与布尔值／`null`，分别消费 `--agui-c-syntax-key/string/number/literal`；括号与分隔符使用 `--agui-c-syntax-punctuation`。语法色属于代码内容，独立于交互和日志状态色，并提供亮暗两套值。数据仍使用 12px 等宽字体、原有缩进与窄面板换行。普通文本、堆栈、超过 32,768 字符的数据，以及加载中或高亮失败时显示纯文本；搜索、脱敏与复制不依赖高亮结果。桌面／本地 CLI 宿主复用 Devframe Shiki service，纯浏览器按需加载 JSON 语法，均不要求额外网络服务。

编辑器布局基于 [Splitpanes](https://antoniandre.github.io/splitpanes/) 实现可拖拽分栏，风格参照 Blender 的区域化布局：

```text
分割条视觉宽度: 1px，悬停与拖动区域向两侧各扩展 3px
分割条颜色:    共用亮暗主题的中性分隔线（--agui-layout-splitter-color → divider）
面板动画:     禁用（transition: none），避免拖拽时的布局抖动
```

## 滚动条

复用 `client/styles/scrollbar.scss`，滑块亮暗配色来自共享 token。每个面板优先只有一个主滚动区；源码、日志可有独立滚动区，长篇创作资料避免每个段落再嵌套滚动框。

## 图标

沿用所在组件的图标族；同一工具栏或面板使用统一笔画、尺寸与对齐。编辑器已有 Carbon / Remix Icon，AGUI 也使用 Radix / Element Plus 等图标，不为单个功能新增一套图标库。文件类型沿用 VS Code Icons；表情仅作为内容，不作为通用工具栏图标。

## 面板组织与示例

面板遵循「标题与局部操作 → 简短状态 → 分组内容」的顺序。计数采用行内元信息，属性采用行，创作资料采用可折叠分组；卡片仅用于有独立边界的实体，例如素材缩略图，不用于包装每个统计值。

以创作上下文面板为例，目标结构为：

```text
创作上下文                   [刷新] [复制给 AI]
three-kingdoms · 已保存的创作资料
章节 1    人物 3    场景 1
────────────────────────────────────────────
▾ 世界观
  桃园起家：世界背景
  作者资料。正式名称未定……
▸ 大纲
▸ 章节
▸ 人物
▸ 场景
```

这是布局参考，不要求面板宽度固定。窄面板可将操作换行或收进菜单，保持主内容可读。原始 Markdown 可以作为明确的源码视图；阅读视图使用正文排版，标题保留层级但限制在面板字号范围内。

| 避免                           | 使用                               |
| ------------------------------ | ---------------------------------- |
| 三个大数字、圆角背景统计卡     | 一行计数或紧凑列表                 |
| 蓝色刷新 + 绿色复制的大按钮    | 同一工具栏内的中性 AGUI 按钮       |
| 每个分组自行选择灰蓝背景       | 共享背景与分隔 token               |
| 大标题、粗体正文、层层嵌套滚动 | 小标题、常规正文、面板主滚动区     |
| AI 面板独有渐变、发光或品牌色  | 与相邻属性面板相同的组件与状态规则 |

## Blender 参考如何落地

参照 [Blender 编辑器 HIG](https://developer.blender.org/docs/features/interface/human_interface_guidelines/editors/) 的区域分工：编辑器头部承载当前区域的操作与显示控制，主区域承载作品，侧栏承载属性。ADV.JS 保留自身组件 API 和主题值，借鉴这种层级组织。

| 区域 / 行为 | ADV.JS 组件与约束                                                                                                                                    |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 区域头部    | `AGUIToolbar`，中性背景，默认约 30px；`label` 命名工具栏，箭头键导航操作；默认可换行，使用 `wrap=false` 时由调用方提供窄面板溢出菜单，不能裁切按钮。 |
| 属性分组    | `AGUIDetails` 原生 disclosure；摘要最小 28px，分隔线、可见键盘焦点、默认正文 12px。                                                                  |
| 属性行      | `AGUIProperty` 标签与控件按 1:2 排列，`for` 关联真实控件 id；长标签可换行，分组窄于 240px 时改为上下排列。                                           |
| 图标操作    | `AGUIIconButton` 最小点击区 24px，默认 14px 图标，mini 不再缩成 9px；`title` 命名，`active` 仅用于切换操作。                                         |
| 长篇内容    | 多行编辑仍可使用顶部标签的 `AGUIFormItem`，通过 `for` 关联输入；不要把正文压成单行属性。                                                             |

角色检查器已接入共享工具栏；角色表单按「基本属性 → 详细描述 → 底部提交操作」组织。字段使用实例内唯一 id，多个检查器不会串联标签。亮暗配色来自 AGUI token，不再为这些区域写固定深灰背景。

### 数值与资源控件

`AGUINumberField` / `AGUINumberSlider` 共用数值编辑实现；默认 24px，保留有效数字、范围限制、禁用与取消编辑语义。字段中央可水平拖动，键盘上下步进；两侧步进按钮保持 24px 点击区。向量轴按可用宽度换行，不能通过压缩到不可读字号维持一行。

`AGUISlider` 基于 Reka UI 的 Root、Track、Range 和 Thumb，继续使用单个数值的 `v-model` 与 `input` 事件；轨道区域默认 24px，轨道 4px、滑块 12px、圆角 2px。填充与滑块使用 AGUI 主色，未填充轨道使用控件边框色，焦点使用独立焦点 token。方向键按 `step` 调节，Home / End 到达边界，PageUp / PageDown 按十个步长调节。可选数值输入与滑块同步，清空草稿后失焦恢复当前值；禁用同时阻止拖动、键盘与输入框修改。滑块通过原生按钮承载 `role="slider"`，保留外部标签的 `for` 与 id 关联。

树行和资源列表默认最小 24px、名称 12px；每级缩进 12px，节点图标 14px，图标与名称间隔 2px。展开箭头靠近节点图标，点击区继续保持 24px，不通过压小点击区收紧视觉间距。选中使用 `--agui-c-selection` / `--agui-c-selection-text`，与焦点环分别表达选中和键盘位置；范围数值的进度也复用选择背景。轴提示使用 `--agui-c-axis-x/y/z/w`，必须同时显示 X/Y/Z/W 标签。图标通过遮罩继承文字颜色，避免白色图标在亮色面板消失。

项目树与素材目录共用目录图标规则：素材集合、章节、人物、场景、图片／背景、音频、视频、模型等常用目录具有对应的中性语义图标，未识别目录回退到普通文件夹。目录名继续显示，图标不替代名称或展开状态。缩略图项之间保留 4px 间距，图片按原比例完整显示，立绘两侧的留白不通过裁切消除；完整文件名与双击／Enter 预览提示通过悬停查看。

资源面板按「局部工具栏 → 目录／内容 → 状态与缩略图尺寸」组织；尺寸滑块要有名称，文件名不能随缩略图缩小到 8px。筛选、空状态、方向键、范围选择、重命名取消及返回焦点属于同一组件契约。

## 开发指南

### 新增组件的推荐方式

1. 先检查 AGUI 是否已有合适组件及变体，复用其实际 API
2. 缺失时查找 [Reka UI](https://reka-ui.com/) 对应的无头组件，在 AGUI 中统一封装
3. 无合适原语时直接基于 Vue 构建，遵循以下约定：
   - 组件名以 `AGUI` 前缀命名（如 `AGUIButton`）
   - 使用 `--agui-*` CSS 变量而非硬编码颜色
   - 控件遵循本页的尺寸与点击区域基线
   - 同时适配亮色 / 暗色模式

### 样式编写约定

- 组件级样式使用 SCSS，放在对应组件目录下
- 全局 token 定义在 `client/styles/css-vars.scss`
- 工具类使用 UnoCSS（Tailwind 语法兼容）
- BEM 命名**不强制**，但类名需以 `agui-` 为前缀或使用组件内作用域

### 迁移与验收

当前已迁移创作上下文、插件管理、AI 工作台、项目欢迎页、预览操作区和流程图外壳，以及通用输入、开关、下拉框、菜单和弹窗。已补齐共享工具栏、图标按钮、属性行、折叠分组，以及角色检查器和角色表单；数值／滑块／向量字段、共享树、资源列表、面包屑与资源工具栏也已接入统一 token 和交互契约。角色列表、角色目录树、详情、立绘、关系和音频库业务面板已复用这些组件；独立角色管理页与停靠面板共用角色条目。欢迎页的项目入口包含标题与说明，允许按钮随两行内容增高，仍使用中性 AGUI 样式；此例外不适用于面板工具栏。其他历史组件继续逐步迁移，不能据此宣称全部界面已完成统一。

已有硬编码颜色、9px mini、局部焦点重置或不一致尺寸不构成新增 UI 的先例。本页定义目标，迁移时修复共享 token/组件，再替换业务面板；不要为满足单个截图叠加局部覆盖。设计例外应在变更说明中写清场景、理由和范围，可复用例外需要更新本页。

UI 变更需记录以下检查结果；尚未完成的检查明确标注：

- 与相邻面板同屏检查字号、按钮、边框、背景和图标是否一致。
- 在 100% 缩放的正常桌面布局（如 1440×900）与约 320px 窄面板分别截图；覆盖长中文/英文标签与长文内容，拖动分割条不遮挡操作或产生无意义横向滚动。
- 验证适用的加载、空、错误、禁用、选中状态，以及 Tab 导航、可见焦点和弹层关闭后的焦点返回。
- 检查暗色默认主题；修改共享组件或 token 时同时检查亮色主题、实际对比度与 200% 缩放后的可操作性。
- 检查刷新、复制、折叠等原有行为保持正常。视觉规范更新本身不代表界面实现已完成迁移。

### 后续迁移顺序

1. 继续迁移文件检查器及剩余历史对话框，优先复用已迁移的共享字段、工具栏和列表。
2. 检查 ColorPicker、Checkbox、文件选择器等剩余控件的标签、禁用、亮色与焦点状态。
3. 继续覆盖完整 Editor 工程工作流与更多 Studio 工程类型。Studio 本地示例、角色／立绘编辑、音频导入／试听与生产版内嵌游戏属于本轮集成回归范围；云登录、素材发布和托管 AI 另行验收。共享控件验收页不替代整站验收。

数值与导航契约由 `agui-numeric.test.ts` / `agui-navigation.test.ts` 回归覆盖。浏览器验收需使用实际 AGUI 组件，检查正常桌面、320px 面板、亮暗模式及 200% 缩放；不将演示数据或临时截图写入项目资源。

### 业务资源面板契约

- 角色条目使用原生按钮，在缩略图和列表视图中保持名称、选中态及键盘激活；列数由可用面板宽度决定，不固定为四列。目录树复用 `AGUITree` 的方向键与焦点规则。
- 角色详情、立绘和关系使用 `AGUIDetails` 分组及 `AGUIProperty` 字段。详情区的操作可由检查器工具栏承载，避免重复显示。删除图标必须包含目标名称。
- 立绘与关系列表以父级持有的角色数据为准，增删发送新对象／数组；切换角色清空输入草稿。立绘名称和地址先去除首尾空格，重复名称提供字段错误，不能直接覆盖已有条目。
- 音频库按「地址与加载 → 搜索 → 条目与试听」排列。仅完整合法的 JSON 响应才能替换已保存的库；地址改变、后续请求或面板销毁时取消旧请求。加载失败保留原列表，并提供可再次执行的加载操作。
- 音频使用带名称的原生媒体控件，`preload="none"` 避免整库预加载；亮暗配色跟随编辑器，播放失败显示重试，条目移除时停止试听。浏览器原生媒体控件允许采用 32px 高度，以保留进度、音量和菜单操作。
