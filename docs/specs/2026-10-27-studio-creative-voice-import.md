## 方案与稳定台词

作者选定 `voice-direction` 后，在制作组核对实际对白。入口同时展示人物／独立旁白的音色和表演建议、发音词典建议，并将具体说话者和稳定 `lineId` 交给既有音色设计、配音任务、试听审阅页面。建议不自动写入 VoiceProfile 或发音词典，不发起生成任务。

台词映射必须同时匹配编译后节点类型、源路径、源位置、说话者和完整显示文本。标准 `@speaker` 两行对白的编译源位置指向指令行，方案指向下一行文本；二者须由同一个真实节点与源文本文字对应。不以人物名或数组下标猜测身份。缺少、歧义或暂不支持的源位置拒绝导入；标准 `> 旁白` 使用独立 narrator 配置；普通文本不冒充旁白节点。当前 Flow 的默认源映射没有行号，入口拒绝猜测；多行语法与完整 Flow 交接仍待接入和验证。

只接受已选定／已采用且来源未变化的方案；在途任务、未知结算、待恢复文字里程碑阻止新写入。导入前重新读取项目，并在锁内核对全项目源版本、方案身份与逐文件原始字节。切换账号／项目／制作组后丢弃迟到结果。

## 真实音频与来源

首个回流入口接受 WAV：最多 32 MiB、120 秒、双声道，原始采样率 8–192 kHz。校验 RIFF／WAVE、分块边界和格式采样信息，通过真实浏览器 `decodeAudioData` 检查音频、时长和声道，限制解码后样本数为 24,000,000，并计算原始字节 SHA-256。文件扩展名和 MIME 不替代字节检查。解码不启动播放，浏览器音频上下文在完成或失败后关闭。

作者必须选择该说话者／项目语言已有的真实 `system` 或 `recorded` 音色绑定，并记录实际制作来源与使用说明。供应商、模型、实际 voice ID、来源类型、VoiceProfile 指纹来自项目绑定；不允许任填一个托管供应商来冒充服务回执。不支持从此入口导入 cloned／designed 服务结果，已有受信宿主流程继续负责这些候选。既有 rights 需完整保留并要求项目中的同意记录存在。

复用项目现有发音词典和台词 `spokenText` 覆盖、`createVoiceTakeEditPlan`、`serializeVoiceLedger` 与 `planAdvAssetManifestUpsert`。记录方案 ID、表演指示、制作说明和原始字节指纹；唯一目标是标准资源目录和 `adv/audio/voice-ledger.json`，不建立另一本配音账本。

## 审阅、登记和独立采用

审阅展示真实时长、原始采样率、字节数、SHA-256、来源与每个文件的完整前后内容；此时正式项目不变。已审阅候选和原始 WAV 现在先保存到私有持久化日志，刷新后可继续审阅；共享恢复协议见[媒体中断恢复规格](./2026-10-27-studio-creative-media-recovery)。

确认“登记未选配音候选”后，媒体、Catalog 和账本在同一工作区写入，`selectedTake` 保持不变。复用项目锁、全版本检查、逐文件 CAS、持久化屏障和写后报错回滚；原始媒体不可覆盖。已登记候选在项目中持久保留，重开只读，不自动再次登记或生成。回执不明时先到已有配音审阅核对，不静默重复导入。登记意图在写入前持久化；重开共用图片／配音的写前、完整写后、部分写入和外部冲突检查。审阅过的部分状态可明确继续或恢复；任意损坏、原生宿主和服务端统一媒体里程碑仍待验收。

之后进入既有配音审阅：从真实文件核验字节、试听，通过作者独立勾选和确认采用绑定；可明确替换或清除选择。本次同时补齐现有 Studio 音频作者事务的 `flush` 确认，以及写入后报错／持久化失败时的回滚。游戏继续读取同一标准 Catalog 和对白账本。改变台词但保留稳定 ID 后，历史 take 保留且显示过期。

## 实际验证与边界

一段中文对白“列车还没有到，我们再等一会儿。”由本机 `/usr/bin/say`、已安装 Tingting 声音、175 wpm 外部制作，再用 ffmpeg 转为 22,050 Hz 单声道 PCM WAV，人工导入 Studio。这是系统语音真实生成的外部素材，不是人工录音，不是 Studio 托管供应商调用，也不是占位测试波形。

实际文件为 125,740 字节、2.849478 秒，SHA-256 `538922a9bbfe31ecd95ab1f8457041d01bdcb0ae8e007fa0253a25bea1177c3e`。Web Chromium 验证原始字节、审阅前不写项目、未选登记、重开、试听时间推进、独立采用、再次重开、正式 `/tabs/play` 的真实 Web Audio 节点完整时长播放，以及修改台词后过期。对浏览器原生方法只添加观察，不替换解码／播放实现或注入播放结果；记录运行中的上下文、非零目标增益与真实 ended 事件，不声称测量物理扬声器或完成人工表演评分。1280／390px 审阅、采用、游戏画面已留证。

真实语音浏览器回归要求通过 `STUDIO_CREATIVE_VOICE_WAV` 提供上述台词的真实语音文件；没有输入时明确跳过该项，不用测试波形补位。运行示例：

```bash
STUDIO_CREATIVE_VOICE_WAV=/absolute/path/dialogue.wav \
pnpm -C apps/studio exec playwright test \
  --config tests/e2e/creative-team.playwright.config.ts \
  --grep 'returns real external speech'
```

方案、账号、任务历史仍是明确 fixture；正式试听、字节存储、事务、采用和播放器为真实产品实现。本机系统语音不证明角色表演质量或六角色模型创作质量。旁白登记有独立单元覆盖，本轮真实浏览器音频只覆盖一个角色；词典建议的受审写回、完整缺失清单、全部章节／Flow 交接、精确媒体下游传播、服务端统一媒体里程碑／采用锚点、Capacitor／原生 SwiftUI 与完整雨夜车站短篇仍未验收。T07／T09／T10 保持未完成。
