## 执行与证据边界

模型只能提出 `playtest-plan`：指定结局、零起始选择序列和待核实疑点。实际报告独立存储为 `CreativePlaytestReport`，不属于模型产物，不因模型自述而完成任务。

`runCreativePlaytest` 从已保存源文件或精确选定的候选版本编译项目。候选只在内存中覆盖，核对来源、上游指纹与同文件冲突；不写正式文件，不替代采用。每条路径创建独立 `createAdvRuntime`，仅执行 `start`、`next` 和指定可见选择的 `choose`，不跳转到目标结局，也不伪造宿主交互结果。内置变量动作使用当前项目的初始变量；不载入外部插件或执行宿主副作用。

报告保存实际快照指纹、程序 ID／hash、完整复现输入、实际指令、状态、文本、进入的节点、选择 ID／序号／标签、变量变化的键和效果类型。静态诊断独立列出，模型提出的疑点标为未核实。

“指定路径通过”要求指定选择全部消耗、实际运行终止，并能从预期结局位置沿无歧义的同章尾部到达终止节点。遇到其他标题、分支或跨章跳转时，不仅凭“曾到过该标题”判定通过。报告保留 `reachedExpected`、实际终止地址和失败原因，不强行修正输入或偷换入口。

编译器新增的节点源映射保存在编译结果中，位于程序及其 hash 之外。Markdown 保留真实行列并映射合并源文件；Flow 当前只知道文件，报告不虚构每个 JSON 节点的行号。源位置按钮使用现有文件编辑器的 `file`／`line`／`column` 路由。

## 上限与未覆盖内容

| 项目 | 当前上限或行为 |
| --- | --- |
| 输入快照 | 沿用 48 KiB 文本、256 文件的创作请求范围；验证指纹。 |
| 路径与选择 | 最多 12 条；每条最多 32 次选择，序号 0–31。 |
| 核心指令 | 默认每条最多 256 条，所有路径合计 512 条；限额前停止，不能标为通过。 |
| 轨迹 | 最多 192 KiB；容量不足明确阻塞，不用截断后的轨迹宣称通过。 |
| 静态诊断 | 最多 32 KiB、128 条；优先错误，注明未保存条数。 |
| 报告 | JSON 最多 256 KiB；解析器检查预算、序列、终止证据及固定未验证声明。 |
| 服务端历史 | 每次运行最多保存 32 份，单独控制行保存报告和冻结输入，运行元数据只放摘要引用。 |

报告固定标明：画面渲染、音频播放、宿主交互、剧情一致性和其他路径未验证。效果中出现 `dialogue.voice` 只表示核心发出了请求，不证明音频存在、已采用或已播放。插件不可用、选择不足、运行错误、取消和容量用尽都保留实际阻塞／失败状态。

## 作者宿主报告的保存

新增服务声明 `authoring.playtestReports`。报告通过已有鉴权、应用 audience、Origin 和限流路径保存；账号、项目和运行决定可访问范围。服务检查来源指纹、候选身份、快照派生、源行范围、报告格式与预算，并以请求键保证幂等；相同键的不同内容报冲突。

服务将其标为 `verification: author-host`，**没有在服务端重放或认证执行结果**。所验证的格式及来源不等于平台已验证路径品质。报告不能修改正式事实、完成角色／制作组、扩大预算、扣点或生成媒体。

报告 POST 的默认 HTTP 上限为 640 KiB，容纳有界报告和可能需要 JSON 转义的冻结源文件；其他任务路由保留 64 KiB。显式设置的全局请求限制仍生效。报告和冻结源文件在单独的存储行中保留，不重复塞入每次运行读取的元数据。

本机使用独立 IndexedDB 数据库 `advjs-studio-creative-playtests`，按账号／项目／运行／请求键保存报告和复现输入，不进入项目导出。存储失败时不承诺重开恢复，也不继续自动同步。同步响应不明时保留同一请求键，重开只读取，作者可以明确重试。

## 过期与复测

执行、打开报告和明确核对版本时重新读取当前项目；源读取及 hash 完成后均核对账号和项目。切换作用域时停止本机执行，丢弃迟到的源读取、报告和同步结果。

核对版本时，当前源须匹配报告的写前基线或候选快照；候选 ID／指纹仍须处于选定或已采用状态。否则报告只作历史证据，不代表当前项目通过。复测载入原报告的选择输入，然后明确执行当前快照，不自动还原旧文件或覆盖作者修改。

采用版本锚点还覆盖本次成果引用的已批准祖先，避免导演计划因自身后续成果采用而过期并反过来污染整条链路；不会因此锚定祖先的所有独立分支。

## 本地验证与剩余要求

本地实际执行覆盖：双结局选择、错误分支、缺失／未用完的选择、悬空引用、不可达章节、指令与轨迹上限、取消、点号地址、原生人物对白、候选隔离、过期和修复后复测。浏览器验证真实核心执行、IndexedDB 恢复、无 POST 重开、报告同步和源定位路由；其身份／历史服务是醒目标注的 fixture，未使用生产模型。

固定 v2 输入可证明选择路径，不作为人物对白绑定或 VoiceTake 验收输入；原生对白另有 `@lin` 编译与核心效果回归。浏览器 fixture 的源定位检查验证路由参数，未挂载正式文件编辑器；真实服务中的整段编辑器导航仍需集成验收。

尚未完成：真实六角色服务短篇、媒体导入与播放验收、剧情设定冲突的独立核实、缺失配音语料验收、负责人自动接收问题并生成修复提案、宿主交互与原生 iOS 接入、服务端重放认证、同预算质量对照和作者盲评。当前报告不能替代这些门槛。
