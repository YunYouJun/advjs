## 当前代码边界

本检出的 `apps/studio-ios` 包含 P0 探针与 P1 共享引擎、StudioKit 库，没有完整原生 App。引擎经版本化 JSON 调用共享 parser、compiler、内容序列化与资源目录；它不提供账号、网络任务、原生项目事务或制作组界面。不要将 Vue 制作组页面嵌入原生作者界面，也不要复制完整 App 到本检出以运行探针。

## Swift 客户端的协议交接

下表路径相对于已登记的制作组根路径；当前实际根路径仍是上节的 Web 路径。所有按运行读取的路径都带 `projectId` 查询参数。协议对象的根层为 `protocolVersion: 1`；能力对象直接返回字段，其他读取分别使用 `items`、`run` 或 `report`，不套用旧单任务的 `data` 解包。

| 操作                 | 路径                                                                                             | 接入约束                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| 能力及历史           | `GET /capabilities`、`GET /runs?projectId=...`                                                   | 先按实际返回的 `enabled`、能力及 `authoring` 兼容位开放界面。            |
| 运行与保存来源       | `GET /runs/:id`、`GET /runs/:id/source-state`                                                    | 来源状态同时含运行与事实指纹；重开先读取，不能隐式再启动。               |
| 开始、作者决定及事实 | `POST /runs`、`POST /runs/:id/decisions`、`POST /runs/:id/facts`                                 | 只提交作者请求与上限，不提交模型选择、派发、结算或产物身份。             |
| 修订、媒体及采用     | `POST /runs/:id/candidate-edits`、`POST /runs/:id/media-candidates`、`POST /runs/:id/milestones` | 先检查对应兼容位，持久化原请求及 `idempotency-key`；选定与写入项目分开。 |
| 试玩与收尾           | `POST /runs/:id/playtests`、`GET /runs/:id/playtests/:reportId`、`POST /runs/:id/delivery`       | 真实宿主证据、同版本实际文件与作者明确决定不可由客户端或模型伪造。       |

`idempotency-key` 是 1–128 个 ASCII 字母、数字、下划线、点、冒号或连字符；同键重放须保留原请求。源码使用 UTF-8 字节计数，当前整份创作源上限为 48 KiB／256 个文本文件；媒体原始字节不塞进源码 JSON。费用、时间和修订字段按共享契约的安全整数范围解码；客户端显示 Runtime 回执，不自行补零、改写预占或把结算未知显示为免费。

完整字段、可选兼容位与有限权限以 `packages/agent/src/creative-team/` 的解析器为准，避免在本清单复制另一份易失效的完整 schema。媒体、试玩、收尾的具体限制分别见其[采用协议](./2026-10-27-studio-creative-adoption)、[试玩协议](./2026-10-27-studio-creative-playtest)及[执行契约](./2026-10-28-studio-creative-execution)。

## 文件兼容回归与复现

`apps/studio-ios/engine/golden/cases.ts` 复用以下原有输入，不创建一份改写后的故事或媒体：

- `packages/agent/test/fixtures/creative-team/v2/project.json`：冻结的中文双结局源项目。
- `packages/agent/test/fixtures/creative-media-author-host.json`：Web 宿主捕获的图片采用与 Markdown 配音登记／选用文件。
- `packages/agent/test/fixtures/creative-playtest-voice-author-host.json`：Web 宿主捕获的 Flow 配音源文件。

回归包含编译、内容索引、校验、作者程序、播放器配置、Catalog、声音设置往返和改稿后的过期诊断。原始用量／历史媒体声明只是捕获的输入；测试没有重新下载、解码或播放它们，也不取得供应商认证。

特别注意：`project.playerConfig` 当前不将图片 Catalog 的人物条目自动映射成角色立绘。上述图片用例证明 Catalog 元数据可编译与往返，不能证明原生播放器已展示该图片。完整 App 仍需接入和验收相同的 Catalog 解析与媒体解析器；不能用“无编译错误”替代 I06。

从仓库根目录运行：

```bash
pnpm -C apps/studio-ios test:engine
```

这会在 Node 及不含 DOM／网络的沙箱中运行共享引擎，并核对打包闭包与体积；不启动模拟器。实际 JavaScriptCore 还需用同一批 golden 输入及同一引擎字节运行 StudioKit 的 `EngineParityTests`。本轮 macOS 临时 Swift 包的精确命令、哈希、输出和清理记录见验收附件。

完整 App 的 iOS 验收必须在包含 `StudioApp.xcodeproj` 的工作区，使用该工作区的 `scripts/simulator-session.mjs` 和现有共享设备。iPhone／iPad 串行测试，保持共享 UDID 锁，不复制完整 App、重建或清空设备来绕过环境问题。不得把 macOS JavaScriptCore、P0 探针或本文件当作原生制作组已通过验收。
