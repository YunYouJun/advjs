## 私有意图与已有记录

保留原有 `advjs-studio-creative-art-imports` 数据库名和图片 `entries` 表，使用版本 2 增加配音 `voiceEntries` 表和账号／项目索引。升级不重命名、复制或删除旧图片候选；原始图片字节、来源、审阅和在途状态保留。恢复记录不写进游戏源码或导出文件。

配音审阅通过后，先持久化原始 WAV、来源、稳定台词和方案指纹、完整文件转换、写前／写后版本，再允许登记。候选可在重开后继续审阅，不再要求重新选择文件。登记开始前持久化 `registering`，完整写入并核对实际源与字节后再记为 `registered`，清除日志中冗余的 WAV；项目原始音频仍保留。登记仍不选择 take，采用状态继续由标准对白账本决定。

配音的恢复写前操作先记 `restoring`，完成后记 `restored`；未写入的意图可以明确放弃为 `abandoned`，原始媒体与记录保留。已登记记录不因之后的台词或采用状态变化而伪装成新的采用回执。

同一账号／项目下，图片采用／撤销与配音登记／恢复在同一个 IndexedDB 事务内检查待处理意图，包含其他制作组的记录。未解决的媒体意图阻止这两个导入口开始新的项目写入，候选暂存仍可进行。每个制作组最多 32 条图片记录、256 条配音记录；未完成媒体的私有二进制合计最多 64 MiB。记录只保存需要的台词引用，不重复保存整份音频作者快照。

## 以实际文件判断

图片和配音共用 `inspectCreativeMediaWrite`。除当前完整项目版本外，还从实际文件重建本次转换的完整写前／写后快照：

1. 每个目标文件必须逐字节等于已审阅的写前或写后内容；新建与删除同样检查。
2. 将所有目标恢复为各自写前值，重建版本必须等于原写前指纹；将其全部换为写后值，版本必须等于原写后指纹。这也保护未由本次操作改变的源文件。
3. 若原始媒体已存在，重新核对其大小和 SHA-256；媒体缺失、已损坏与已被作者替换分别处理，不覆盖未知文件。

| 实际状态 | 判断与作者操作 |
| --- | --- |
| `before` | 源仍完整匹配写前版本，已存在媒体必须通过核验；可明确继续，或放弃未写绑定的意图。 |
| `after` | 源完整匹配写后版本且媒体核验通过；回执丢失时只确认本机记录，不再写项目。 |
| `partial` | 目标文件为审阅过的两版本混合，其他源未变；或写后源完整但原始媒体缺失。作者可审阅后继续或恢复写前文件；继续仍需可用原始字节。 |
| `conflict` | 某个目标包含第三种内容、独立源已改变，或原始媒体与指纹不同；禁止自动继续或覆盖，保留资料供人工处理。 |

检查与重开只读取文件。继续或恢复始终要求明确操作，并在正常项目写入锁内重新检查刚读取的部分版本、每个文件和原始媒体；排队期间有作者保存时拒绝。恢复写前只改变本次已审阅文件，原始图片／音频保留以便复用，不删除独立素材。

未写入的意图可以在独立文件已经被作者修改时放弃：必须证明本次所有目标仍为原写前内容，此操作只关闭私有意图，不修改项目。图片撤销意图的放弃采用对应写后检查。任一绑定文件已经改变时不能靠“放弃”掩盖部分写入。

## 已执行的验证

单元测试枚举三个目标文本与媒体存在性的 16 种子集，验证只读判断、继续、恢复和原始字节保留；覆盖独立／目标作者修改、未知媒体、缺少原始字节、排队期间变化与范围切换。配音日志另覆盖审阅重开、意图落盘失败、写后确认丢失、部分登记恢复／还原和放弃未写入意图。

浏览器使用真实中文对白 WAV 和仓库已有 WebP。在真实 Studio 内存文件系统写入媒体及第一个文本文件、等待 IndexedDB 持久化后，保持原写入 Promise 未结束并刷新页面；旧执行上下文因此终止，回滚不会代替恢复。重开后项目保持实测部分状态，写入次数为零，再经实际 UI 完成登记或恢复写前内容。另验证配音写后确认丢失的只读对账、图片部分采用阻止新配音写入及原文件恢复。

旧库升级用原生 IndexedDB 建立原始版本 1 表结构和真实图片候选，再由实际 Dexie 版本 2 打开；保留的原始字节经正常审阅采用后与 Catalog 指纹一致。方案／身份／任务历史仍为明确 fixture；文件、持久化、解码、恢复和正式播放使用产品实现。

## 尚未覆盖的范围

这是本机媒体操作协议，不授予通用文字里程碑媒体权限，不把本机记录当作服务端认证或制作组采用锚点，也不自动完成角色任务。服务端不可变媒体候选、统一准备／确认、精确下游传播和跨设备接续仍待接通。

当前跨媒体意图检查覆盖这两个导入口；所有编辑器、导出和试玩的待恢复状态门禁、多窗口写入协调、原生目录宿主与 Capacitor／SwiftUI 尚未验收。真实硬件故障造成的任意损坏文件仍须人工冲突审阅；本轮未实现任意同文件合并。完整雨夜车站短篇、真实服务及单 Agent 对照评测也不由这些恢复测试证明，T07／T09／T10 保持未完成。
