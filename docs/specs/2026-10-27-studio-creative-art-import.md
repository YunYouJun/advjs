- 范围：[主计划 T06／T09](../plans/2026-10-27-studio-creative-team) 的人工图片回流；实际证据见[验收记录](../reports/2026-10-27-studio-creative-team-acceptance)。

## 交互与来源

作者从已选定美术方案的稳定 `assetId` 选择需求，提供文件、来源与可选内容许可。支持 PNG、JPEG、WebP，单张最多 20 MiB；按文件签名识别格式，通过浏览器真实解码取得尺寸，并计算原始字节 SHA-256。文件扩展名、调用方 MIME 和模型 URL 不授予媒体采用权限。尺寸上限为单边 16,384、总计 64,000,000 像素；实际尺寸与方案不同时明确显示，采用保留原图尺寸。

候选私有存储于 `advjs-studio-creative-art-imports`，按账号、项目和制作组隔离，保留具体方案指纹、需求、图片指纹和来源说明。未确认采用的二进制与恢复记录不写进游戏源码。每个作用域最多 32 条记录、未采用字节合计最多 64 MiB；作者可明确移除候选记录。采用并核对项目字节后清除私有候选中的冗余二进制，项目原图仍保留。

## 目录与绑定

复用 `planAdvAssetManifestUpsert`，唯一可写根仍为 `adv/assets.json`；支持内联与分片目录，保留既有本地根和远端 Profile。原图按内容哈希命名，使用相对路径；目录记录 MIME、真实尺寸、字节数、来源及许可，不把暂时的 Blob URL 写进项目。

角色与表情使用既有 Catalog `kind: character`、`characterId`、`expression` 绑定；默认画像为 `default`，人物档案须已采用且稳定 ID 存在。背景使用场景卡的 `assetId`，必要时创建对应 Scene；Location 继续仅为关联地点，不替代 Scene。更新场景前置字段时保留未知字段与正文，旧 `src` 由明确审阅的稳定 ID 引用取代。

同一个角色／表情已有另一资源 ID 时拒绝隐式覆盖。替换相同资源 ID 的不同内容需作者选择“审阅同 ID 替换”。Review 展示每个目录与场景文件的完整写前／写后内容，并编译候选项目；未知人物、场景或资源冲突必须先处理。旧 `adv/assets/index.json` 不由此入口隐式迁移。

## 写入、恢复与撤销

确认采用前持久化本机操作意图。实际写入复用 `commitStudioProjectFiles` 的项目锁、逐文件 CAS、全项目版本核对和持久化屏障，将图片、目录和场景绑定作为同一次原生工作区操作；源文件失败或持久化失败时回滚本轮新增字节与已写文本。已存在的相同路径必须通过字节核验，损坏或被作者替换的文件不会被覆盖。

后端在写完二进制后才报错时，同样回收本次新增文件；写入前就失败时不尝试删除不存在的文件。保存事实、方案身份和作用域在异步操作边界重复核对，切账号／项目／制作组丢弃迟到候选，方案版本改变则阻止旧采用。

重开只读取项目和意图，不自动再次采用，也不发出生成请求。写后记录尚未确认时，核对实际源码版本与图片字节：写前可以明确继续或放弃；写后仅确认本机记录；不匹配时保留资料并要求人工核对。撤销要求项目仍与采用后的精确版本一致，恢复目录与绑定的原始文本，不删除可复用的原图。作者中途保存文件后，自动撤销被阻止。

## 已验证与尚未交付

Web 浏览器实际导入仓库已有的小云 WebP（619 × 619），核对预览、候选重开、采用前正式文件不变、采用后的字节／目录一致、重开恢复和条件撤销。再次采用后离开 fixture，打开正式 `/tabs/play`，由实际 `GamePlayer` 和目录适配器读取项目 Blob 并显示角色图片。美术方案、账号与任务历史为明确 fixture；这张既有素材不是新生成的雨夜车站美术品质样本。

桌面／窄屏审阅与正式播放器截图分别检查，窄屏工具栏的次要操作收进菜单，宿主运行时检查器与游戏菜单分开摆放。截图保留实际游戏动画并在视口变化后核对图片已加载、可见和进入视口，避免截图工具关闭动画产生空白证据。

此入口暂时只形成本机媒体操作记录，尚未接入制作组服务的统一媒体里程碑、采用锚点与跨设备接续；不因此将服务端艺术任务改成已采用或完成。背景／表情有目录与绑定实现及单元回归，本轮真实游戏显示证据只覆盖默认角色画像。真实服务方案质量、风格一致性、媒体变更后的精确下游传播、Capacitor／原生 SwiftUI、图片托管生成及配音闭环仍需独立验收。T06／T09／T10 保持未完成。
