# 雪夜庄园 — AI 剧本杀

> ADV.JS Studio 辅助示范作品 · 技术深度展示

## 概述

1920 年代的英国乡间庄园，一场暴风雪之夜，庄园主在书房中被发现死亡。
六位宾客被困庄园，每个人都有秘密，每个人都有嫌疑。

这不是传统的剧本杀——AI 控制所有 NPC 角色，根据玩家的调查方向动态释放线索，
世界时钟推进案件发展，每一轮对话都可能改变推理方向。

## 展示 ADV.JS 全栈技术

| ADV.JS 特性            | 在本案例中的体现                              |
| ---------------------- | --------------------------------------------- |
| **多人协作**           | 多位玩家分别调查不同 NPC，线索共享            |
| **AI 角色对话**        | 6 个 NPC 各有独立人格、秘密和说谎策略         |
| **角色状态系统**       | 嫌疑值、好感度、紧张度、已获线索              |
| **世界时钟**           | 案件时间线推进：发现尸体 → 搜查 → 对峙 → 真相 |
| **分支叙事**           | 调查顺序和提问方式决定能获得的信息            |
| **Y.Map/Y.Array 协同** | 线索面板实时同步，多人拼图                    |

## 技术亮点

1. **AI NPC 的"说谎"系统**：每个角色有 `secret` 和 `lie_strategy` 字段，AI 会根据好感度和压力决定何时松口
2. **线索收敛机制**：世界时钟推进后，NPC 行为变化（紧张度上升、新线索浮现）
3. **多人线索拼图**：通过 Y.Map 同步已发现线索，一人发现的线索立刻出现在所有玩家的面板上
