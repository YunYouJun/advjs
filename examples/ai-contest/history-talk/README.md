# 跨越时空的对谈 — AI 历史人物对话

> ADV.JS Studio 主打示范作品 · AI 大赛 Demo 展示

## 概述

与三位改变世界的历史人物面对面对话：**孔子**、**艾伦·图灵**、**达芬奇**。

每位人物拥有独特的性格、知识边界和对话风格。他们会用自己的方式思考你的问题，
有时回答你，有时反问你，有时沉默片刻后给出一个你意想不到的角度。

## 展示核心

| ADV.JS 特性   | 在本案例中的体现                                   |
| ------------- | -------------------------------------------------- |
| AI 角色对话   | 三位人物各有独立 system prompt，保持历史人格一致性 |
| 角色状态系统  | 好感度、话题解锁进度、对话深度                     |
| 分支叙事      | 玩家提问方向决定对话走向，不同话题树               |
| 世界时钟      | 三个时空场景自由切换                               |
| Markdown 创作 | 全部内容用 Markdown 编写，零门槛创作               |

## 90 秒 Demo 脚本

1. **开场（10s）**：展示 Studio 编辑器，Markdown 角色卡一览
2. **与孔子对话（25s）**：问"什么是仁？"，孔子用论语式对话反问
3. **切换到图灵（25s）**：问"机器能思考吗？"，图灵展开图灵测试推理
4. **与达芬奇（20s）**：问"如何成为通才？"，达芬奇用观察笔记式回答
5. **展示创作流程（10s）**：修改角色卡 → 即时生效，零门槛
6. **收尾（10s）**：三人同框，"跨越时空的对谈，从一份 Markdown 开始"

## 素材来源

基于公开历史资料编写，角色对话风格参考原始文献翻译。
不声称代表真实历史人物观点，仅为创意演绎。
